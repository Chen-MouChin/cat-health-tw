文章怎麼產生

  1. 選題 以台灣飼主實際會遇到的問題為主：常見疾病、急診判斷、飲食、行為、法規與費用。
  2. 先找來源，再寫文章 每篇文章動筆前先確定有一級學術來源可引用。沒有可靠來源的主題不寫。 來源清單全部收錄在 學術文獻庫。
  3. AI 起草 Claude 依指定來源撰寫初稿，要求每個數值、劑量、分期標準都標明出處。
  4. 數值核對 檢查腳本會標出每一個帶數字、卻沒有註腳的句子，以及品牌名稱與絕對化用語。每個註腳都必須對應文獻庫裡的一筆資料，再逐項比對那筆資料的內容是否真的支持這句話。對不上的數字直接刪除，或改寫成不帶數字的描述，不猜。
  5. 人工審核 Chen-MouChin 逐篇閱讀，對照每個註腳的上下文與文獻摘要，必要時打開原文；也檢查語氣、是否有品牌置入。通過才改標為「已審核」並公開。
  6. 定期重審 已審核文章每 12 個月重看一次，或在引用的指引改版時立即重審。頁面顯示最後審核日期。

審稿流程：一個數字怎麼上線

我們不是獸醫師，所以不靠「相信我們」，而是讓每個說法都能被你自己查回去。

文章裡的內容分成兩種

類型是什麼在頁面上怎麼看出來
指引原文的內容 分期門檻、檢驗數值、劑量、疫苗時程、研究結果、法規條文。這些我們只轉述，不自己推算，也不從多個來源湊出一個新數字。 句尾有編號，例如 1，點了到文末參考文獻，再到文獻庫看那筆資料
我們的整理 章節安排、白話說明、把幾份指引放在同一張表比較、「哪些情況建議請獸醫看看」的歸納，以及台灣在地的就醫與法規資訊。 沒有編號的句子。整理的依據是有編號的內容，但寫法是我們的

一個數字要通過這幾關

  1. 有出處才能寫 寫作規範要求每個數值、劑量、比例、年齡門檻句尾都帶註腳。沒有可引用的來源，就不寫數字，改用「多數」「少數」這類描述。
  2. 出處要真的支持這句話 註腳指向文獻庫的一筆資料。我們先讀那筆資料的中文摘要，確認它真的講了這件事才放上去，不憑印象引用。
  3. 文獻本身要核對過原文 文獻庫每一筆都標示狀態。「已審核」代表我們打開原文逐項比對過摘要與數字，並確認網址有效；「待審」代表還沒做完這一步。狀態在 文獻庫公開，任何人都能看。
  4. 人工通過才公開 文章經人工審核才會出現在網站上，頁面顯示審核日期。還沒審完的草稿不公開，也不給搜尋引擎。
  5. 來源有分歧時兩邊都寫 不同指引意見不一致時，同時列出並說明差在哪裡，不替讀者選邊。

我們不寫的東西

  • 沒有來源的台灣統計，例如「台灣三成的貓有某病」。
  • 單一個案或飼主社群的經驗分享，即使很常見。
  • 替你判斷要不要就醫、要不要用某種治療。這些交給看過你的貓的獸醫。

目前沒有獸醫師參與審稿。如果之後有獸醫師審閱，文章頁會寫出審閱者姓名與日期。

  • Frontiers 系列期刊，無例外。
  • 寵物用品品牌的官方衛教、飼料廠商白皮書。
  • 內容農場、未署名部落格、社群貼文、AI 生成網頁。
  • 任何我們無法取得原文核對的資料。

引用方式

  • 具體數值（分期標準、劑量、目標值、盛行率）必須在句內標出來源，不能只在文末列參考清單。
  • 文獻庫的中文摘要一律改寫（paraphrase），不複製原文段落，尊重著作權。
  • 引用的是「來源怎麼說」，不是「我們認為」。來源之間有分歧時，同時呈現並說明。

利益衝突與廣告

  • 不接業配、不寫贊助文、不放聯盟行銷連結。
  • 文章中不推薦特定品牌。提到處方飼料或藥物時使用通用名稱，例如「腎臟處方飲食」「Amlodipine」，不出現商品名。
  • 網站唯一收入是 Google AdSense 自動投放廣告。廣告內容由 Google 決定，編輯無法介入，廣告主與文章內容無關。
  • 每頁廣告位有上限，不做彈窗、不做擋內容的插頁。

更正政策

我們會出錯。發現錯誤時：

  • 事實錯誤（數值、劑量、分期）：確認後 7 天內修正，文章底部註記更正日期與內容。
  • 可能危及貓咪安全的錯誤（例如劑量錯誤）：確認後立即修正或下架該段落。
  • 已審核文章若被降回草稿，會從網站與 sitemap 移除，修正後重新審核。

回報管道：關於本站頁面的回饋表單，或直接在 GitHub 開 Issue。 所有修改都留在公開的 git 紀錄裡，任何人都能查到誰在什麼時候改了什麼。

我們做不到的事

  • 我們不是獸醫師，不能診斷、不能開藥、不能取代任何一次門診。
  • 文章描述的是一般情況與國際指引。你的貓是個案，只有看過它的獸醫師能判斷。
  • 貓出現呼吸困難、無法排尿、抽搐、大量出血或誤食毒物時，建議直接聯絡獸醫或附近的 24 小時動物醫院，由獸醫判斷，不必先查文章。
