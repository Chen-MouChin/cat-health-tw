貓咪危險物質速查

⚠️ 懷疑中毒立即就醫，不要等症狀出現。
百合、葡萄、木糖醇超過治療窗口即無解藥。

🚨 最致命的三件事

⚡ 重點百合腎衰（18h 不可逆）、蔥蒜溶血（煮熟更毒）、巧克力／木糖醇／葡萄無解藥（只能越早送醫）。

1. 真百合（Lilium）與金針花（Hemerocallis）= 貓第一殺手
不只葉花，花粉、花瓶水、舔到毛上的花粉都致命。台灣節慶花束（母親節／情人節／年節）常含百合。FDA 明確指出：延遲超過 18 小時治療，多半進入不可逆腎衰竭。

⚠️ 但和平百合（peace lily／白鶴芋）、海芋（calla lily／馬蹄蓮）中文叫「百合」但不是真百合，只含草酸鈣引起口腔刺激，不會腎衰竭（VCA）。

2. 蔥蒜洋蔥韭菜（Allium 屬）= 滷肉飯陷阱
機制：硫化物氧化紅血球 → Heinz body → 溶血性貧血。台灣家常滷汁、炒飯、蒜蓉醬、麻辣鍋底都含。煮熟、脫水粉末（洋蔥粉）毒性反而更濃。少量長期累積也會慢性傷害紅血球。

3. 巧克力 / 木糖醇 / 葡萄 — 沒有解藥
這三類沒有專門解毒劑。唯一能做的：越早送醫，由獸醫催吐、給活性碳、打點滴把毒物排掉／減少吸收。越晚處理傷害越深。

🌸 百合專章（貓咪第一殺手）

⚡ 重點只有真百合（Lilium）與金針花（Hemerocallis）會腎衰；和平百合、海芋是假百合，只口腔刺激。18h 是不可逆分界線。

哪些是真百合（會導致腎衰竭）

Lilium 屬：虎斑百合、亞洲百合、復活節百合（Easter lily）、星辰百合（Stargazer）、玫瑰百合（Roselily）、日本華麗百合
Hemerocallis 屬：金針花 / 萱草

哪些叫「百合」但不是真百合

中文名 學名 真實毒性
和平百合 / 白鶴芋 Spathiphyllum 草酸鈣，口腔刺激，不致腎衰
海芋 / 馬蹄蓮 Zantedeschia 草酸鈣，口腔刺激
君子蘭 Clivia 輕度嘔吐

中毒時序（依 FDA 衛教資料）

時間 可能出現
0–12 小時 嘔吐、流口水、精神差、食慾不振
12–24 小時 多尿、脫水，腎指數開始飆
24–72 小時 急性腎衰竭，未治療多半死亡
> 18 小時介入 多半不可逆（FDA 明確警告）

致命劑量與急救

  • 少於 1–2 片葉或花瓣即可致命（Pet Poison Helpline）
  • iCatCare 建議 1–6 小時內 最佳治療窗：催吐 → 活性碳 → 洗掉毛上花粉 → IV 利尿支持腎臟

🔴 其他高度危險（立即就醫）

⚡ 重點煮熟不會變安全，洋蔥粉反而更濃；葡萄／巧克力／木糖醇無安全劑量，一口就可能出事。
物質 機制 台灣常見陷阱
🧅 蔥蒜洋蔥韭菜 溶血 滷肉飯、炒飯、蒜蓉醬、麻辣鍋、韭菜盒子；貓舔人盤就可能中
🍇 葡萄 / 葡萄乾 急性腎衰（機制未明） 麵包、燕麥棒、堅果什錦；無安全劑量
🍫 巧克力 methylxanthine → 心律不整 / 癲癇 黑巧 > 牛奶巧 > 白巧，黑巧克力最毒
🍬 木糖醇 低血糖 + 肝毒 無糖口香糖、人用牙膏、無糖零食
🍷 酒精 神經 / 肝毒 米酒料理、紹興酒、發酵生麵團
☕ 咖啡因 同巧克力 咖啡渣、茶包、能量飲料

🟡 中度危險（觀察 + 電話諮詢獸醫）

⚡ 重點草酸鈣類植物會口腔灼痛但不致命；聖誕紅民間誇大，實際上只輕微刺激。
物質 哪裡會遇到 主要傷害
🌷 杜鵑花 春季庭園 / 陽台 心律不整
🌷 鬱金香 / 水仙球根 年節花禮、花市 嘔吐 + 心臟症狀
🪴 黛粉葉 / 萬年青 辦公室、客廳盆栽 口腔灼痛（草酸鈣）
🪴 黃金葛 / 蘆薈 常見室內植物 同上
🥜 夏威夷豆 堅果零食 後肢虛弱、顫抖
🥑 酪梨（果肉／核／葉） — 含 persin
🌭 過鹹加工食物 香腸、貢丸、火鍋料 電解質失衡
🍞 生麵團（含酵母） 自製麵包未烤前 脹氣 + 酒精中毒
🐟 長期生魚 — 維生素 B1 缺乏

🌹 聖誕紅民間誇大 — 多數只輕微口腔刺激，不致命（VCA）。

✅ 對貓相對安全的植物

⚡ 重點「相對安全」≠ 鼓勵啃食；大量誤食任何植物都可能嘔吐，放高處為佳。
  • 貓草（小麥草 / 大麥草 / 燕麥草）
  • 貓薄荷 catnip
  • 吊蘭 / 蝴蝶蘭 / 非洲紫羅蘭
  • 虎尾蘭（啃食會不適但非致命）
  • 玫瑰（注意刺）

完整清單查 ASPCA Toxic and Non-Toxic Plants（可搜任何植物）。

🚑 誤食後 SOP

⚡ 重點不要自己催吐 → 先打電話給獸醫 → 帶包裝／植物殘片／嘔吐物拍照就醫。台灣沒有寵物專用毒物熱線，直接衝 24h 急診。

1. 不要自己催吐 — 除非獸醫電話指示
腐蝕性毒物（強酸鹼、家用清潔劑）催吐會二次灼傷食道。

2. 立刻打電話給獸醫
- 我家貓吃了什麼（拍包裝 / 植物照）
- 估計時間與攝入量
- 貓的體重

3. 帶樣本就醫 — 包裝、植物殘片、嘔吐物拍照都帶

4. 台灣沒有寵物專用 24h 毒物熱線 — 直接衝 24h 急診動物醫院最穩

🏠 居家防誤食 checklist

⚡ 重點花束進門前先挑百合、料理後洗手、化學品上鎖、陽台植物買前查 ASPCA。
  • 📮 花束收貨前檢查 — 含百合整束退回或送人
  • 🔪 料理時蔥蒜不掉地；用後洗手再摸貓
  • 🧴 清潔劑、人類藥品、保健品（含木糖醇）放高處或鎖櫃
  • 🌿 陽台植物買之前對照 ASPCA 清單
  • 🎒 年節花禮先告知送禮者：有貓不收百合
