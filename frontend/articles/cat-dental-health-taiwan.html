貓咪口腔健康完整指南

大多數人細心挑飼料、定期驅蟲，卻忽略了貓的牙齒。
3 歲以上貓 70% 有牙周病、30-60% 有 FORL 牙吸收症 — 這是貓最常見也最被忽略的健康問題。

🚨 兩件最該知道的事

1. 口腔細菌會入血 — 影響腎臟、心臟、肝臟，縮短壽命，不只是口臭問題。

2. 「不麻醉洗牙」沒用且傷害大
ICatCare 明確反對 — 只能清潔可見部分，無法處理最重要的牙齦下結石，也無法做 X 光診斷 FORL。健康貓全麻風險 < 0.5%。

🦷 為什麼會出問題

時程 變化
進食後 24h 形成牙菌斑（plaque）
48-72h 礦化成牙結石（無法刷掉）
持續 牙齦炎 → 牙周炎 → 齒槽骨流失、牙齒鬆動
長期 細菌入血 → 心、腎、肝風險

🪥 居家刷牙：3 週漸進訓練

工具

  • 貓專用牙刷或指套
  • 貓專用牙膏（雞肉 / 鮪魚口味）
  • 🚫 絕對不能用人用牙膏 — 含氟化物 + 木糖醇對貓有毒

3 週訓練計劃

週次 做什麼 目標
W1 手指沾牙膏給貓舔 接受氣味 + 手在嘴邊
W2 指套或紗布輕摩擦牙齦外側 習慣口腔被觸碰
W3 換牙刷，從犬齒開始，45° 角刷牙齦交界 完整刷牙動作

技巧：
- 每次刷完給零食 / 玩具強化正向連結
- 每次 30 秒夠了，重點是牙齦線外側
- 抗拒就退一階段，不要硬來
- 已有牙齦炎 → 先看獸醫評估再開始

🩺 全麻洗牙 — 流程 + 費用

為什麼要全麻

貓無法乖乖張嘴。麻醉不是讓貓不亂動，而是：
- 才能清潔齒縫 + 牙齦下
- 才能拍 X 光診斷 FORL
- 才能拔除患齒

台灣費用（2026 參考）

項目 費用
術前血檢 $1,500-3,000
超音波洗牙（含麻醉） $3,000-8,000
拔牙（每顆） $500-2,000
完整洗牙含拔 1-3 顆 $5,000-8,000

建議頻率

  • 每年一次口腔檢查
  • 全麻洗牙 1-3 年一次（看個別狀況）

⚠️ FORL 牙吸收症（最常被忽略）

台灣成貓 30-60% 中招。牙齒從根部被自身破骨細胞侵蝕，初期肉眼看不到，只能在全麻 X 光下確診。

症狀

  • 用單側嚼食
  • 吃到一半突停、甩頭
  • 流口水、輕觸下巴就縮
  • 嚴重時牙齦增生覆蓋牙齒

唯一治療

拔除患牙。聽起來嚇人，但拔牙後多數貓食慾大增 — 長期疼痛終於解除。

🚨 何時要立刻看醫生

  • 口臭突然加重（特別是腐敗味）
  • 持續流口水或口水帶血絲
  • 食慾下降 / 體重減輕
  • 用一側嚼或吃到一半就停
  • 觸碰下巴或臉部異常反應
  • 完全不吃 + 嚴重口臭 → 可能口炎（FCGS），立即就醫

🛒 輔助產品（無法取代刷牙）

產品 效果 注意
VOHC 認證潔牙零食（如 Greenies 貓用） 有實證減少牙菌斑 認準 VOHC 標章
潔牙飼料（如 Hill's t/d） 物理摩擦 需獸醫建議才用
飲水添加劑 輔助效果有限 確認貓接受口味

🚫 避免：標榜「潔牙」但無 VOHC 認證或實證的零食。
