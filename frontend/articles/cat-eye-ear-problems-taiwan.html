貓咪眼睛與耳朵問題完整指南

DRAFT本文為 AI 草稿，尚未經人工審核校對，醫療資訊請務必再次與獸醫師確認，勿據此自行診斷或用藥。

五官疾病初期飼主自己可看出端倪。
辨識、居家清潔、何時就醫三件事學會就夠用。

兩件最該記住的事

1. 不要用人用眼藥水 / 棉棒深入耳道
人用眼藥水成分可能有害；棉棒深入會推入分泌物或傷耳膜。

2. 角膜潰瘍是緊急，可能影響視力
眼球混濁 + 瞇眼 + 畏光 + 爪子抓眼，立即就醫。

眼睛問題

分泌物顏色判讀

分泌物 可能原因 處理
少量透明 / 淡褐 正常淚液氧化、輕微刺激 觀察
淡黃色黏性 輕度結膜炎（可能病毒性） 建議就醫
濃黃 / 綠膿狀 細菌感染、嚴重結膜炎 🚨 就醫
血色 創傷、嚴重感染 🚨 就醫

常見眼疾

結膜炎（最常見）

原因：
- FHV-1（貓疱疹病毒），最常見，眼分泌物 + 打噴嚏
- FCV（卡里西病毒），較少
- 貓披衣菌，單眼開始後擴雙眼
- 細菌繼發感染

治療：獸醫開抗病毒 / 抗生素眼藥水。禁用人用眼藥水。

角膜潰瘍

症狀：瞇眼 / 閉眼、眼球表面混濁、畏光流淚、爪子抓眼。
警告：未治療可能深化，嚴重影響視力甚至需摘除眼球。
治療：抗病毒眼藥水（Cidofovir）+ 護膜藥膏；嚴重需手術。

眼瞼內翻（Entropion）

眼瞼內翻、睫毛刺激角膜。波斯 / 異短等扁鼻品種常見。
治療：手術矯正。

第三眼瞼脫出（Cherry Eye）

瞬膜腺體脫出，眼角紅色突起。
治療：手術複位（不可切除），切除會影響淚液分泌。

葡萄膜炎（Uveitis）

眼球內部發炎，可能是全身病的眼部表現（FIV / FIP / 高血壓 / 腫瘤）。
症狀：眼混濁、虹膜變色、不等瞳孔、畏光。
治療：需系統性評估，不是只開眼藥水。

居家清潔

  1. 無菌生理食鹽水（0.9% NaCl）或乾淨溫水
  2. 乾淨棉球或無菌紗布
  3. 從眼角向外擦拭，每次新棉球
  4. 不要用力摩擦

禁用：人用抗生素眼藥水、類固醇眼藥水（未確認無角膜潰瘍前）。

眼睛立即就醫

  • 眼球明顯混濁
  • 眼球突出或凹陷
  • 嚴重損傷
  • 不停用爪抓眼
  • 伴全身症狀（嗜睡、不進食）

耳朵問題

兩大常見原因

否 耳疥蟲 耳炎
病原 Otodectes cynotis 寄生蟲 細菌 / 黴菌
分泌物 深褐 / 黑色乾燥（像咖啡渣） 黃色 / 深棕油性
異味 可能有 黴菌性特別臭
搔耳強度 強烈 通常較輕
觸碰反應 不一定 疼痛（縮頭、嗥叫）
傳染性 高，多貓家庭一隻有就全染 不會

耳疥蟲

好發：幼貓、多貓家庭、收容所
診斷：獸醫顯微鏡確認，或取分泌物塗黑紙看白色小點移動
治療：
- 外用滴劑（含 selamectin，或 fluralaner 加 moxidectin 的貓用配方）可同時處理成蟲與蟲卵
- 家中所有貓同時治療（高度傳染）
- 清耳去分泌物幫助藥物接觸

耳炎（外耳炎 Otitis Externa）

常見原因（按比例）：
- 過敏（食物 / 環境），最常見潛在原因
- 耳道濕氣（洗澡後未擦乾）
- 異物（草種、棉棒碎片）
- 解剖異常（耳道狹窄）

治療：需獸醫確認病原
- 細菌性：抗生素耳藥水
- 黴菌性：抗黴菌耳藥水
- 混合：複合製劑

慢性耳炎要找根本原因（通常是過敏），否則反覆復發。

居家耳朵清潔

步驟：
1. 貓咪專用耳道清潔液（不可酒精、不可棉花棒深入）
2. 倒入清潔液
3. 輕揉耳道根部 30 秒（液體聲音正常）
4. 讓貓自己甩出
5. 乾淨棉球擦外耳道，只清可見範圍

絕不要：
- 棉棒深入耳道（可能推入分泌物或傷耳膜）
- 雙氧水或酒精（刺激性強）

頻率：
- 正常貓，不需常規清潔
- 過敏 / 耳炎病史，每 1-2 週一次

耳朵就醫信號

  • 分泌物多且異味
  • 觸摸耳道極度敏感（疼痛）
  • 頭部傾斜（可能中耳炎）
  • 對聲音反應減少（聽力下降）
