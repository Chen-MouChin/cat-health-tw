貓咪居家安全完整清單

貓的好奇心 + 台灣高樓密集 + 開門短暫 = 三大居家風險。
新貓到家前就要排查完。

🚨 三件最該記住的事

1. 「貓有九條命」是迷思
2-5 樓墜落比高樓更嚴重（沒時間翻正反射）。即使翻正成功也會骨折 / 內出血 / 氣胸。

2. 精油對貓高毒
茶樹油、薰衣草高濃度、尤加利、柑橘類精油 — 貓肝臟無法代謝。家中不要用擴香。

3. 線狀物可致命
線、橡皮筋、緞帶 — 貓舌頭倒刺含進去吐不出來，腸道穿孔風險。

✅ 室內危險排查清單

⚡ 電線 / 電氣

  • [ ] 電線束起或用保護套（貓愛啃）
  • [ ] 延長線不放地面
  • [ ] 加熱設備有安全關閉

🧪 有毒化學品

  • [ ] 清潔劑 / 漂白水 / 消毒水放有門櫃子
  • [ ] 馬桶蓋關閉（清潔錠的水有毒）
  • [ ] 洗衣精膠囊放高處（高濃度有毒）
  • [ ] 🚫 不用精油擴香（茶樹 / 薰衣草 / 尤加利 / 柑橘對貓毒）

🍫 食物危險

  • [ ] 蔥蒜韭菜密閉容器
  • [ ] 巧克力 / 葡萄 / 葡萄乾收好
  • [ ] 含木糖醇食品（無糖口香糖）放安全
  • [ ] 垃圾桶有蓋（咖啡渣、骨頭碎片）
  • 詳見 危險物質速查

🔧 物理危險

  • [ ] 洗衣機 / 乾燥機每次使用前檢查貓是否躲入
  • [ ] 冰箱開關門注意貓位置
  • [ ] 高處窗台防墜網
  • [ ] 陽台欄杆間距 < 8cm（幼貓會卡）

🪡 小物件吞食

  • [ ] 縫衣針、線、橡皮筋放抽屜
  • [ ] 耳機 / USB 線束起
  • [ ] 藥品（人 + 寵物）放有鎖抽屜或高處

🐈 藏身處安全

  • [ ] 沙發底部無釘子或尖銳突出
  • [ ] 牆壁洞口封住
  • [ ] 冰箱後面間隙不卡

🏢 陽台 / 窗戶防墜（台灣高樓必做）

高空症候群現實

「翻正反射」救不了：
- 2-5 樓反而最嚴重（時間不夠展開）
- 7 樓以上存活率低，但存活者也通常需緊急手術
- 即使「看起來沒事」也要就醫（內出血可延遲數小時才出現）

常見墜落情境

  • 紗窗被推破（台灣標準紗窗擋不住貓）
  • 陽台欄杆縫隙擠出
  • 帶上頂樓陽台「曬太陽」
  • 睡眠中無意識滾下窗台

有效防護

方案 適合 費用
防貓網（不鏽鋼或 PP 尼龍） 自有住宅最推 $3,000-15,000
隱形鐵窗（細密格柵） 有圍欄者 視面積
窗台護欄（兒童 / 寵物） 部分窗戶 $300-1,500（IKEA / 寵物店）
DIY 拆卸寵物柵欄 租屋族 $500-3,000

🏠 租屋族溝通策略

  • 請房東允許可拆卸裝置（魔術氈 / 掛鉤、不破壞牆面）
  • 說明動物安全 — 多數房東理解
  • 押金擔保安裝後恢復原狀

🚪 防逃脫 — 雙重門禁

最常逃家情境

  1. 門口瞬間衝出（開門最常見）
  2. 施工 / 搬家期間
  3. 紗窗破損或氣窗未關
  4. 搬到新家後嘗試「回家」

玄關「氣閘設計」

  • 大門 + 室內間設第二道阻擋
  • 矮柵欄 / 全身高柵欄 / 磁吸自動彈回門
  • 任何時刻只能開一扇門

訓練「門口規矩」

  • 用零食強化「退後」指令
  • 進門前搖鑰匙 = 退開信號
  • 訪客進門前告知有貓

搬家期間

  • 全程隔離固定房間，門口貼警示
  • 新家頭 2-4 週不接觸門口

🏷 必做的身份識別

晶片（台灣法定義務）

  • 動保法規定貓需植入晶片並戶籍登記
  • 是唯一不會脫落的身份識別
  • 費用 $300-500（獸醫執行）
  • 登記：縣市動保機關或獸醫院協助

頸圈 + 識別牌（晶片以外的補強）

  • 防勾型頸圈（被勾住可自動脫落，避免窒息）
  • 刻手機號碼的金屬牌
  • 響鈴型 → 知道貓在哪

近期照片（每年更新）

  • 全身正面 + 側面
  • 特殊標記（斑點 / 顏色分佈）

🆘 走失後 SOP（前 48 小時最關鍵）

  1. 搜索附近 100 公尺（床下、鄰居雜物間、高處 + 低處）
  2. 走失點放用過的貓砂 + 臥具（氣味引導）
  3. 張貼啟事：實體（電線桿、公告欄）+ Facebook 社區群組
  4. 通報當地動物收容所
  5. 夜間尋貓：黑夜易看到貓眼反光、貓夜間活躍

萬一墜落

  1. 不要移動（懷疑脊椎傷時）
  2. 用平板或紙板托住整個身體
  3. 立刻送最近急診（查獸醫院）
  4. 告知從幾樓墜落 → 醫師排查傷害
