貓咪預防保健 — 疫苗時程 + 年度健檢完整指南

貓咪預防保健完整指南

預防勝於治療 — 疫苗 + 健檢是貓咪健康的兩大支柱。
貓擅長隱藏病痛，沒有定期健檢，疾病發現時通常已晚期。

🚨 三件最該記住的事

1. 純室內貓也要打三合一
貓瘟病毒（FPV）可從你鞋底 / 衣物帶入，且可在環境存活數年。

2. 台灣家貓狂犬病疫苗非強制（不同於犬隻）
完全室外 + 接觸野生動物的貓建議打。純室內貓風險極低。

3. SDMA 比肌酸酐更早偵測 CKD（可偵測到更早期的腎功能下降）
7+ 歲老貓健檢一定要加。

💉 第一部分：疫苗

核心疫苗：三合一（FVRCP）

字母 疾病 症狀
FVR 貓鼻氣管炎（疱疹病毒 FHV-1） 打噴嚏、眼鼻分泌物、發燒；感染後終生潛伏
C 卡里西病毒（FCV） 口腔潰瘍、流涎、跛行、上呼吸道感染
P 貓瘟（FPV） 嚴重腸胃炎、免疫崩潰，幼貓死亡率極高

幼貓接種時程

週齡 接種 說明
6-8 週 三合一第 1 劑 母源抗體開始消退
10-12 週 三合一第 2 劑 間隔 3-4 週補強
14-16 週 三合一第 3 劑 + 狂犬（如需） 最關鍵一劑，不可省略
1 年後 加強 之後核心疫苗每 3 年

為什麼 3 劑？ 母源抗體會干擾疫苗免疫反應，無法精確知道何時消退。連續 3 劑確保至少一劑在母源抗體消退後施打。

成貓補強（WSAVA）

疫苗 頻率
三合一（核心） 完成幼貓系列後 1 年加強，此後每 3 年一次
狂犬病 視個別情況（見下方）

WSAVA：貓瘟疫苗免疫持久性 > 3 年，不需每年施打。可用抗體效價檢測（titer test）替代。（WSAVA 指引最新版為 2024 年）

非核心疫苗（視個別）

疫苗 適用 備註
FeLV 貓白血病 戶外活動、接觸其他貓 幼貓建議
FIV 貓愛滋 未結紮會打架的戶外公貓 台灣市售效果存疑
披衣菌 多貓 / 眼分泌物問題 通常含五合一中

五合一（三合一 + FeLV + 披衣菌）= 多貓家庭、偶爾外出、收容所貓。

🇹🇼 狂犬病的真相

家貓無法規強制接種（不同於犬）。台灣 2013 年於鼬獾族群重新確認狂犬病，部分山區屬疫區。

對象 法規
家犬 ✅ 法定每年強制
家貓 ❌ 目前無強制，建議性質

建議接種：完全室外貓 / 可能接觸野生動物。純室內貓風險極低，與獸醫評估。

含佐劑 vs 無佐劑

含佐劑 無佐劑
免疫效果 良好 良好
注射部位反應 較明顯 較輕微
FISS 注射部位肉瘤風險 相對較高 相對較低
三合一價格 $300-600 $800-1,200

→ 預算允許優先選無佐劑（特別是核心疫苗 + 狂犬）

接種前後

前：
- 健康狀況良好（發燒 / 腹瀉 / 急症延後）
- 告知近期用藥 / 手術
- 驅蟲後 1-2 週再接種（避免免疫資源分散）

後 24-48h：
- 輕微嗜睡、食慾↓ → 正常 1-2 天恢復
- 注射部位輕微腫 → 正常 2 週內消退
- ⚠️ 腫脹持續 > 3 個月 → 排除 FISS

🚨 立即就醫（過敏反應）：嚴重嘔吐腹瀉 / 顫抖虛弱 / 呼吸困難 / 顏面或喉嚨腫脹

🩺 第二部分：定期健檢

健檢頻率

年齡 頻率 主要目的
幼貓（0-1 歲） 每 3-4 週（疫苗期間） 疫苗、驅蟲、生長監測
成貓（1-7 歲） 每年一次 疾病篩檢、疫苗、口腔
中老貓（7-11 歲） 每年（建議半年） 甲狀腺、腎臟、血壓
老貓（11+） 每半年一次 CKD、糖尿病、高血壓管理

AAFP：7+ 歲半年一次健檢可大幅提高早期疾病偵測率。

基礎理學檢查

獸醫的雙手是最重要工具：
- 體重 + 體態評分（BCS 1-9）
- 眼睛（角膜、結膜、眼底 — 老貓高血壓可見視網膜變化）
- 耳朵（耳疥蟲、慢性耳炎）
- 口腔（牙周病是成貓最常見疾病之一，2 歲以上發生率極高）
- 淋巴結（腫大可能感染或腫瘤）
- 腹部觸診（腸、腎、膀胱、腫塊）
- 皮膚毛髮（過敏、外寄生蟲）

加做項目（成貓以上）

  • CBC + 生化：肝腎功能、血糖、電解質
  • 尿液分析：比重、蛋白質、葡萄糖、沉渣
  • 血壓（特別老貓 — 高血壓在老貓非常常見）
  • T4（7+ 歲建議每年 — 甲亢是老貓第二常見內分泌病）

老年套餐（7+ 歲全套）

以上全部 +
- SDMA（腎早期 — 比肌酸酐更早偵測到 CKD）
- 胸腔 X 光（心臟大小、肺部）
- 腹腔超音波（腎、肝、腸形態）

🐈 讓健檢壓力更小

  • 外出籠適應訓練 — 平時放家中讓貓自由進出
  • 就醫前一晚通常不需禁食（抽血需 4-6 小時空腹，先電話確認）
  • 選 Cat Friendly Practice 認證診所（ISFM 認證、貓犬分隔候診、低壓力處置）
  • Feliway 噴外出籠減輕焦慮

❓ 常見問題

Q. 純室內貓還要打疫苗？
要。FPV 可從你鞋底/衣物帶入，FHV-1 極普遍，多貓家庭或就醫接觸都有風險。

Q. 成貓不確定打過什麼怎麼補？
從三合一開始，間隔 3-4 週打第 2 劑，之後按成貓時程。可抽血做 titer test 確認免疫狀態。

Q. 三合一每年打嗎？
WSAVA：完成幼貓系列+1 歲補強後，每 3 年一次即可。

Q. 接種多久才有保護力？
7-14 天後產生有效免疫。期間避免接觸可能帶病原的其他動物。

Q. 健檢結果「偏高/偏低」要恐慌嗎？
不要。許多指數要結合完整臨床表現。獸醫會說明哪些要立即處理、哪些觀察追蹤。

免責聲明：整理自 WSAVA、AAFP、ABCD、ICatCare、ISFM、VCA。疫苗計畫應依個別狀況與獸醫討論制定。
