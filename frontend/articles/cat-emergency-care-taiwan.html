貓咪急診判斷與居家急救 SOP

⚠️ 核心原則：急救只是穩定狀況、爭取送醫時間，不要在家「治療」。
寧可去看醫生也不要等待 — 貓天性隱藏痛苦，明顯症狀出現時通常不在早期。

🚨 兩件最該記住的事

1. 公貓無法排尿 = 24–48 小時內可致命
尿道阻塞是公貓最常見的致命急症。一次都尿不出來、頻繁進廁所擺姿勢但沒尿，現在就走，不要等天亮。

2. 不要催吐 / 不要在家「治療」
除非獸醫電話指示。部分毒物催吐會二次傷害。所有急救動作都只是為了穩定狀況送醫。

🔴 立即急診（現在就去）

數小時內可能致命：

症狀 可能原因
完全無法排尿（尤其公貓） 尿道阻塞
呼吸困難 / 張口呼吸 心臟病、胸水、氣喘
嘴唇 / 牙齦發白、紫、藍 缺氧、循環衰竭
後肢突然癱瘓 主動脈栓塞（ATE）
癲癇 > 2 分鐘 腦病變、中毒、低血糖
確認誤食毒物 百合、殺蟲劑、人藥、大量蔥蒜
嚴重外傷（車禍 / 高墜 / 被咬） 內出血可能無外觀
突然失明（瞳孔放大無對光反應） 高血壓、視網膜剝離
體溫過冷或過熱（觸感冰或燙） 體溫調節失敗
意識不清、叫不醒 休克、昏迷前兆
大量出血止不住 血管撕裂

🚗 查最近 24h 急診醫院 — 開「📍 用我的位置 + 🚨 24h 急診」即可。

🟠 今天就醫（白天盡快，勿拖 24h）

症狀 為什麼不能拖
完全不吃不喝 > 24h 48h 不進食可能引發脂肪肝
嘔吐 > 3 次 / 天 或連 2 天 偶發正常，頻繁是問題
腹瀉帶血 / 黏液 / 水狀 感染、寄生蟲、腸炎
排尿哀叫、頻繁進廁所（母貓 / 公貓輕症） 膀胱炎 / FLUTD
打噴嚏 + 流鼻水 + 眼屎（同時） 上呼吸道感染
跛行 > 1 天 骨折、關節傷、感染
一個月內體重明顯下降 甲亢 / 糖尿病 / 腎病 / 腫瘤早期
大型傷口或膿瘍 貓打架咬傷易膿瘍

🟡 本週預約（觀察 1-2 天，勿超過一週）

食慾輕微下降、偶爾嘔吐（每週 1-2 次）、偶發打噴嚏、抓耳偶發、喝水量持續增加 > 1 週、毛髮光澤變差。

老貓「喝水量增加」要特別警惕 — CKD 或甲亢早期。

🟢 一般觀察（居家可處理）

毛球嘔吐後正常、疫苗後 24h 嗜睡、結紮術後 1-2 天行動緩慢、新環境躲藏、換食期間軟便。

🚑 5 種急症的就醫前 SOP

1️⃣ 中毒懷疑

✅ 應做：立刻帶離毒源 / 皮膚沾到用溫水沖（戴手套）/ 記錄毒物名 + 時間 + 量 / 帶包裝就醫
❌ 不要：自行催吐、餵活性碳、餵牛奶

2️⃣ 骨折懷疑

✅ 最小化移動 / 放硬紙板或平底盒 / 毛巾鬆散包裹（不綁緊） / 立刻送醫
❌ 不要試圖固定 / 不要拉直肢體

3️⃣ 大量出血

✅ 乾淨毛巾或紗布直接壓迫傷口 / 持續壓迫不掀起 / 邊壓邊送醫
❌ 不要用止血帶（除四肢外組織壞死風險）

4️⃣ 窒息 / 呼吸困難

看到喉嚨異物：用手指輕取（不深推）
看不到：不要做人工呼吸（除非獸醫電話指導）→ 直接送醫

5️⃣ 低體溫（溺水 / 過冷）

✅ 毛巾擦乾 / 包毯子 / 送醫
❌ 不要用電毯（貓無法自行移開，過熱危險）

🔍 隱藏疼痛 — 貓的「沉默信號」

貓天生隱藏弱點。注意這些：

  • 躲到平時不去的地方（衣櫃深處、床底）
  • 梳理突然停止（毛凌亂）或過度舔特定部位
  • 不願被碰、平時溫順突然亂咬
  • 在廁所外排泄、排泄姿勢改變
  • 叫聲改變（變多或變少都算）
  • 眼睛微瞇（Cat Grimace Scale 疼痛量表特徵）
  • 不願跳躍 / 跳前猶豫

📋 就醫前 60 秒準備清單

到醫院能說出這些就是金幣：

  1. 症狀何時開始 + 突發 vs 漸進
  2. 頻率（今天幾次 / 多久一次）
  3. 最後一次進食 + 有無換食
  4. 最近接觸過什麼新東西（植物 / 食物 / 藥物 / 外出）
  5. 貓砂盆使用次數變化
  6. 錄影（抽搐、步態、呼吸節律 — 間歇性症狀超有用）

🎒 居家急救包（建議常備）

  • 🚑 24h 急診醫院電話（先查好貼冰箱）
  • 💉 無針注射器（補水 / 給藥）
  • 🩹 止血紗布
  • 💧 生理食鹽水（沖洗眼睛 / 傷口）
  • 🌡 直腸體溫計（正常 38-39.2°C）
  • 📦 運輸籠（永遠放在手邊）
