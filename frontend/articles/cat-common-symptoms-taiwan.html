貓常見症狀速查

三個飼主最常忽略的症狀 — 都可能是大病早期信號。
本文教你何時可以觀察、何時必須就醫。

🚨 三件最該記住的事

1. 「我家貓就是容易吐」可能是 IBD 或腎病早期
獸醫一般建議：每週嘔吐 > 1 次或持續 1 個月以上，就該安排全面評估。

2. 便秘 > 3 天可發展成不可逆巨結腸症
早期積極處理是關鍵。

3. 老貓體重下降 + 吃很多 = 八九不離十甲狀腺亢進
老貓 7 歲後建議常規篩 T4。

🤮 嘔吐

三種「嘔吐」要分清

類型 樣貌 含義
真性嘔吐 腹部用力收縮、帶出胃內容物（食物 / 黃膽汁 / 毛球） 胃或小腸問題
乾嘔 腹部收縮但吐不出，或只吐泡沫 ⚠️ 可能腸道阻塞
反芻 食道被動推回、無腹部收縮、食物完整 食道問題

常見原因

原因 特點 嚴重
飲食過快 剛吃完吐出完整食物 低（用慢食碗）
毛球 管狀 低（除非阻塞）
換食 軟便+嘔吐 低（緩慢換糧）
食物不耐 反覆，特定食物後 中
腸胃炎 急性多次 中-高
異物吞入 急性、持續、乾嘔 高（可能手術）
腸道阻塞 乾嘔、腹脹、停止排便 🚨 緊急
CKD 老貓+多尿多飲 高
甲亢 老貓+多食消瘦 高
胰腺炎 劇烈嘔吐+腹痛 高

🚨 嘔吐立即就醫 7 信號

  1. 反覆乾嘔，吐不出任何東西（腸阻塞）
  2. 嘔吐物有血（鮮紅或咖啡色）
  3. 24 小時內嘔吐 > 5 次
  4. 完全停止進食 / 飲水
  5. 精神萎靡、虛弱、無法站立
  6. 腹部膨脹或疼痛
  7. 嘔吐 + 多尿多飲（可能 CKD / 糖尿病）

慢性嘔吐 ≠ 正常

獸醫一般建議：每週 > 1 次或持續 1 個月以上 → 全面評估（血液 + X 光 / 超音波）。
慢性嘔吐常見原因：IBD、腸道淋巴瘤、CKD、甲亢。

居家應急（非緊急）

1-2 次嘔吐 + 精神正常無上述信號 →
- 禁食 4-6 小時（不禁水）讓腸胃休息
- 之後少量易消化食物（水煮雞胸、低脂罐）
- 觀察 24 小時 → 仍吐就醫

💩 便秘

何時算便秘

正常 1-2 次 / 日，最長不超過 2 天。> 2-3 天無排便要注意。

嚴重度判斷

程度 症狀 處理
早期 進出砂盆多但排便少、糞便乾硬 居家緩解
中度 > 2 天無排便、用力但排不出、食慾略降 居家試 24h，無改善就醫
嚴重 > 3 天無排便、腹部硬、嘔吐、不進食 🚨 立即就醫

常見原因

原因 說明
脫水 / 飲水不足 最常見，乾食族特別
纖維失衡 太少或太多
毛球積累 阻礙腸道
缺乏運動 老貓、肥胖
直腸異物 誤食骨頭
關節炎 蹲下排便太痛
藥物副作用 部分止痛藥、抗組織胺
神經系統問題 脊椎傷
巨結腸症 慢性便秘晚期

居家緩解（輕度）

水分補充（最重要）
- 換濕食或乾糧加溫水
- 流動飲水機
- 多個位置擺水碗

纖維補充
- 南瓜泥（無糖無鹽）：每餐 1-2 茶匙
- 貓草
- 亞車前子殼（Psyllium）：少量混食

腹部按摩
- 指尖順時針輕揉 2-3 分鐘
- 每日 2 次，貓咪不適應就停

增加活動
- 逗貓棒遊戲增加腸蠕動

⚠️ 巨結腸症（Megacolon）

反覆嚴重便秘被忽視 → 結腸長期擴張喪失蠕動能力 → 幾乎不可逆，需終生管理，嚴重需手術切除部分結腸。

預防關鍵：早期積極處理便秘 + 充足飲水 + 必要時長期軟便劑（獸醫指示）。

🚫 絕不可自行用人用灌腸劑 — 對貓有毒。

⚖️ 體重下降

何時擔心

  • 體重 ↓ > 10%（4kg 貓減 400g+）
  • 持續下降而非單次波動
  • 伴隨其他症狀

建議：每月固定量體重記錄趨勢（不只看單一數值）。

症狀組合對應疾病

體重↓ + 食慾↑ = 甲狀腺亢進（老貓最常見）

  • 吃多但消瘦
  • 多飲多尿
  • 夜間活躍嚎叫
  • 心跳加速
  • 診斷：T4 血液檢查（7 歲後建議常規篩）

體重↓ + 多飲多尿 = CKD 或糖尿病

CKD：食慾↓、嘔吐、口臭（氨臭）。診斷：血液生化 + 尿比重
糖尿病：食慾好但消瘦、大量喝水多尿、後腿姿勢異常。診斷：血糖 + 尿糖

體重↓ + 慢性嘔吐腹瀉 = IBD 或腸道腫瘤

（IBD 與淋巴瘤需活體切片區別）

體重↓ + 吞嚥困難 = 口腔 / 食道問題

觀察咀嚼後吐出、頭偏一側 → 嚴重牙周病或口腔腫瘤。

診斷基本流程

  1. 完整理學檢查（觸診甲狀腺、腹部腫塊）
  2. 全血球 + 生化（腎、肝、血糖）
  3. T4（老貓常規）
  4. 尿液 + 比重
  5. 視情況：腹腔超音波

年輕貓（< 7 歲）體重下降

特別注意：寄生蟲（鉤蟲、弓蛔蟲）/ FIV / FeLV / 腸道感染。
