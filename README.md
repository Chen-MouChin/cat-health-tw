# 貓健康站

台灣的貓健康知識庫：醫療知識文章、全台動物醫院查詢、品種圖鑑與文獻庫。

- 網站：https://chen-mouchin.github.io/cat-health-tw/
- 回饋與勘誤：[GitHub Issue](https://github.com/Chen-MouChin/cat-health-tw/issues/new)

## 網站有什麼

- **醫療知識文章**：疾病、照顧、飲食、環境等主題，經過兩段人工審稿才上線。目前文章還在審稿中，尚未公開。
- **獸醫院查詢**：全台 22 縣市約 2,000 家動物醫院，可篩 24 小時醫院，也可以依目前位置找附近的醫院。位置只在瀏覽器裡計算距離，不會傳到伺服器。
- **品種圖鑑**：68 個品種，含遺傳疾病警示，每條警示都附出處。
- **文獻庫**：文章引用的指引與論文，每筆附原文連結，多數附中文摘要。

## 內容原則

- **學術與衛教出處**：只引用 ISFM、iCatCare、WSAVA、IRIS、AAFP（FelineVMA）、AAHA、Cornell 貓健康中心、VCA、ASPCA、FDA、美國獸醫學會（AVMA）的期刊（JAVMA、AJVR），以及 PubMed 上可公開取得全文的論文。不引用 Frontiers 期刊。
- **台灣出處**：法規、統計與公告引用政府原始頁面（全國法規資料庫、農業部、衛福部、各縣市動保處）。
- **審稿**：AI 協助起草，人工初審與核准後才上線。分工與流程寫在[編輯方針](https://chen-mouchin.github.io/cat-health-tw/editorial.html)。
- **語氣**：醫療內容用建議的語氣，說明哪些情況建議請獸醫看看。
- **商業**：不推薦品牌、不列價格表。

網站內容僅供參考，貓的健康狀況請以獸醫師的診斷為準。
