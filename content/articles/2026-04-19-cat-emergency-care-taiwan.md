# 貓咪急診判斷與居家急救：何時該衝醫院，路上能做什麼

貓天生會隱藏痛苦。當你看得出牠不對勁時，通常已經不是早期。這篇把常見症狀分成四級，讓你在慌張的時候有個對照表；再說明五種急症在送醫路上能做與不能做的事。核心原則只有一句：急救是為了穩定狀況、爭取送醫時間，不是在家治療[^VCA-EMERGENCY-SIGNS]。

## 何時該立刻就醫

🚨 以下任一情況，數小時內可能致命，現在就出門：

| 症狀 | 可能原因 |
|---|---|
| 公貓頻繁蹲砂盆卻沒有尿 | 尿道阻塞，24 到 48 小時內可致命 |
| 呼吸困難、張口呼吸、腹部用力呼吸 | 心臟病、胸水、氣喘、外傷 |
| 牙齦發白、發紫或發藍 | 缺氧、休克、內出血 |
| 後肢突然癱瘓、腳掌冰冷 | 主動脈血栓 |
| 抽搐超過 2 分鐘，或連續抽搐 | 中毒、腦病變、低血糖 |
| 確認誤食毒物 | 百合、殺蟲劑、人用藥、大量蔥蒜 |
| 車禍、高處墜落、被狗咬 | 內出血可能沒有外傷 |
| 突然失明、瞳孔放大不縮 | 高血壓、視網膜剝離 |
| 體溫摸起來冰冷或發燙、叫不醒 | 休克、中暑、失溫 |
| 大量出血壓不住 | 血管撕裂 |

本站[獸醫院查詢](../vets.html?only24h=1)可篩選 24 小時急診，出門前先打電話告知狀況，醫院能提前準備。

## 30 秒重點

1. **公貓沒有尿等於急診。** 一次都尿不出來、一直蹲砂盆擺姿勢，現在就走，不要等天亮。詳見[公貓尿道阻塞](male-cat-urethral-obstruction.html)。
2. **不要自己催吐、不要在家治療。** 部分毒物催吐會造成二次傷害，人用藥對貓多半有毒。所有動作只為了穩定狀況送醫。
3. **錄影比描述有用。** 抽搐、步態異常、呼吸方式，用手機錄下來給獸醫看，比你事後回想準確得多。

## 四級判斷表

### 第二級：今天就醫，不要拖過 24 小時

| 症狀 | 為什麼不能拖 |
|---|---|
| 完全不吃不喝超過 24 小時 | 貓超過 48 小時不進食可能引發脂肪肝 |
| 一天嘔吐超過 3 次，或連續 2 天嘔吐 | 偶發正常，頻繁是問題 |
| 腹瀉帶血、黏液或呈水狀 | 感染、寄生蟲、腸炎 |
| 排尿時哀叫、頻繁進砂盆但有尿（母貓或公貓輕症） | 膀胱炎，公貓可能進展為阻塞 |
| 打噴嚏、流鼻水、眼屎同時出現 | 上呼吸道感染，幼貓惡化快 |
| 跛行超過 1 天 | 骨折、關節傷、咬傷膿瘍 |
| 一個月內體重明顯下降 | 甲亢、糖尿病、腎病、腫瘤的早期表現 |
| 大型傷口或腫脹的膿瘍 | 貓咬傷極易化膿 |

### 第三級：本週預約，觀察不超過一週

食慾輕微下降、每週偶爾嘔吐一兩次、偶發打噴嚏、抓耳朵、飲水量增加超過一週、毛髮光澤變差。

老貓「喝水變多」要特別留意，這是腎病與甲亢最早的訊號之一。

### 第四級：居家觀察即可

吐毛球後精神正常、疫苗後 24 小時內嗜睡、結紮術後一兩天行動緩慢、到新環境躲藏、換食期間軟便。

## 五種急症的就醫前處置

### 懷疑中毒

**做**：立刻把貓帶離毒源；皮膚或毛沾到就戴手套用溫水沖洗；記下毒物名稱、時間、量；帶包裝或植物殘片一起去醫院。

**不做**：自行催吐、餵活性碳、餵牛奶。腐蝕性毒物催吐會二次灼傷食道，牛奶對多數毒物無效。台灣沒有寵物專用的毒物諮詢熱線，直接去 24 小時急診最快。詳見[貓咪危險物質速查](cat-toxic-substances-taiwan.html)。

### 懷疑骨折

**做**：減少移動，把貓放在硬紙板或平底盒上，用毛巾鬆鬆地包住不綁緊，立刻送醫。

**不做**：試圖固定或拉直肢體，那會加重疼痛與損傷。

### 大量出血

**做**：用乾淨毛巾或紗布直接壓迫傷口，持續壓著不要掀開看，邊壓邊送醫。

**不做**：綁止血帶。除非是四肢且獸醫電話指示，否則止血帶造成的組織壞死風險高於好處。

### 窒息或呼吸困難

看得到喉嚨異物：用手指輕輕取出，不要往深處推。看不到：不要做人工呼吸（除非獸醫電話指導），直接送醫。運送時保持外出籠通風、避免壓迫胸部。

### 失溫

溺水、淋雨、冬天被關在外面：用毛巾擦乾，裹毯子，送醫。**不要用電毯**，失溫的貓無法自己移開，容易燙傷。

## 貓的「沉默信號」

貓隱藏疼痛，但會留下線索：

- 躲到平時不去的地方（衣櫃深處、床底）
- 突然不梳毛（毛變凌亂）或過度舔某一個部位
- 不願被碰，平時溫馴的貓突然咬人
- 在砂盆外排泄，或排泄姿勢改變
- 叫聲變多或變少
- 眼睛微瞇、耳朵往後、鬍鬚往後貼（貓臉部疼痛量表的典型特徵）
- 不願跳躍，或跳之前猶豫

出現這些變化時，往「第二級」的方向想，不要等。

## 就醫前 60 秒準備

到醫院能講出這六件事，獸醫能省下很多時間：

1. 症狀什麼時候開始，突然發生還是逐漸變化
2. 頻率：今天幾次、多久一次
3. 最後一次進食的時間，最近有沒有換食
4. 最近接觸過什麼新東西：植物、食物、藥物、外出
5. 貓砂盆使用次數的變化
6. 手機錄影：抽搐、步態、呼吸節律，間歇性症狀尤其有用

## 居家急救包

- 24 小時急診醫院的電話與地址，先查好貼在冰箱上
- 無針注射器（餵水、餵藥）
- 止血紗布與乾淨毛巾
- 生理食鹽水（沖洗眼睛與傷口）
- 直腸體溫計，正常體溫約 38 到 39.2°C
- 外出籠固定放在拿得到的地方，不要收進儲藏室

## 常見問題

**Q. 半夜貓吐了一次，精神還好，要去急診嗎？**
單次嘔吐、精神食慾正常，可以觀察到早上。但若是公貓同時一直進砂盆、或嘔吐帶血、或接下來還吐，就不要等。

**Q. 貓從陽台掉下去但看起來沒事，要看醫生嗎？**
要。內出血與氣胸可能延遲數小時才出現症狀。任何樓層的墜落都應該當天就醫。

**Q. 急診費用大概多少？**
台灣 24 小時急診通常有夜間加成，初診加基本檢查數千元起，住院另計。事先準備緊急備用金，見[養貓財務規劃](cat-cost-insurance-taiwan.html)。

**Q. 可以先給貓吃人的止痛藥嗎？**
不可以。乙醯胺酚（普拿疼）對貓是致命毒物，布洛芬等消炎止痛藥也會造成腎衰竭與胃出血。
