# 貓的自然行為解讀

> 貓不會說話 — 但身體每個部位都在說話。
> 讀懂這些信號 = **避免誤讀被咬抓 + 看出隱形壓力 + 建立深厚人貓關係**。

---

## 🚨 三件最該記住的事

**1. 翻肚不是「摸我肚子」邀請**
是信任的表示，但**貿然摸腹部會引發本能防禦**（摸了就咬）— 不是壞貓，是反射。

**2. 搖尾巴 ≠ 開心**（跟狗相反）
快速甩尾 = **煩躁警告**。看到立刻停手。

**3. 直視 = 挑釁信號**
跟貓建立眼神接觸用**慢眨眼**（slow blink）+ 移開視線，不要盯著看。

---

## 🐈 第一部分：肢體語言

### 尾巴 — 最直觀的情緒指標

| 尾巴姿態 | 意義 |
|---|---|
| 高舉垂直，尾尖微彎 | 友善問候、開心見到你 |
| 高舉，尾尖輕顫 | 非常開心、興奮 |
| 高舉但**炸毛膨大** | 極度興奮或受驚 |
| 夾在兩腿之間 | 焦慮、恐懼、臣服 |
| 低垂、微微搖擺 | 放鬆休息 |
| **快速左右猛甩** | 🚨 **煩躁警告 — 停手** |
| 緩慢大幅搖擺 | 專注（如打獵前） |

### 耳朵 — 情緒的精細溫度計

- **朝前豎立** → 好奇、專注、友善
- **略向外轉**（飛機耳） → 輕度煩躁、不確定
- **完全向後貼頭**（飛機耳+壓低） → 🚨 恐懼或攻擊警告
- **快速轉動** → 高度警覺

### 眼睛

**瞳孔大小**（要考量光線）：
- 細縫（強光下） → 放鬆或輕度侵略
- 放大 → 興奮、恐懼、黑暗、疼痛 — 結合其他信號判斷
- 全圓（正常光下） → 可能恐懼或疼痛

**眼瞼與注視**：
- **慢眨眼**（Slow Blink） → ❤️ **表達信任**。可以回應，是**跨物種友善信號**
- **直視不眨** → 🚨 警告或挑釁
- 半瞇眼 → 放鬆、滿足

> **「貓咪之吻」實驗**：貓放鬆時對牠慢眨，等待回應。許多貓會慢眨回答 — 純粹的社交聯繫。

### 姿勢

#### 放鬆信號
- **麵包姿**（四肢藏身下） → 完全放鬆、有安全感
- **側躺露腹** → 極度信任（**但非觸摸邀請**！）
- 慢甩尾、半閉眼

#### 恐懼防禦
- 身體壓低、重心後移、耳朵後壓
- **炸毛**（讓自己看起來更大）
- 弓背側對攻擊者

#### 🚨 攻擊前 5 個警告（看到立刻停）

1. 尾巴快速抽打
2. 皮膚顫動（背部微抽動）
3. 耳朵後壓
4. 瞳孔放大
5. 低沉嘶吼或哈氣

→ 看到任何一個，**停止動作 + 給空間 + 給出口**。

### 常見誤讀

| 行為 | 民間誤解 | 正確 |
|---|---|---|
| 翻肚 | 摸我肚子 | 信任表示，**非觸摸邀請** |
| 搖尾巴 | 開心 | **煩躁警告** |
| 凝視 | 友善 | **挑釁信號** |

## 🛁 第二部分：梳理行為

### 為什麼貓花 5 小時梳毛

每天醒著時間的 30-50% 用在梳理。多重功能：

**實際功能**：
- 清除污垢、寄生蟲、死毛
- 刺激皮脂分泌（防水保溫）
- 夏天蒸發唾液**輔助體溫調節**
- 整理毛髮降低氣味（狩獵時減少被察覺）

**心理功能（轉移行為）**：
緊張不知所措下會突然開始梳毛 — 類似人類緊張揉頭髮。
**你跟貓大聲說話後牠突然舔腳 → 很可能是壓力反應**。

### 互相梳毛（Allogrooming）

兩隻貓互梳頭頸（自己舔不到的地方）= 社交信任 + 群體身份認同（共同氣味）。
**多貓家庭：互梳頻率是評估貓咪關係品質的重要指標**。

### ⚠️ 過度梳毛 — 心理 or 身體？

**警訊**：反覆過度梳同部位 → 禿毛 / 破皮 / 對稱性禿（腹、大腿內、背）

**先排除身體原因**：
- 跳蚤過敏皮膚炎（腰背部）
- 食物過敏（廣泛性）
- 環境過敏（季節性）

**心因性禿毛**（Psychogenic Alopecia）：排除身體後，若禿毛與壓力事件相關（換新家、新成員、搬家）→ 心理原因。

**治療**：
- 找出並消除壓力源
- 環境豐富化（[參考](cat-environment-enrichment-taiwan.html)）
- 嚴重時 → 行為獸醫師評估，可能需抗焦慮藥

### 🚨 突然停止梳理也是警訊
毛雜亂打結 → 通常代表：
- 身體不舒服（疼痛、發燒）
- 憂鬱或嚴重壓力
- 老貓**關節炎**無法彎身梳理

→ 盡快就醫。

## 🎮 第三部分：玩耍

### 狩獵循環本質

```
尋覓 → 蹲伏觀察 → 衝刺 → 撲抓 → 咬咬 → 滿足感
```

完整走完才能帶來心理「滿足」。**用逗貓棒互動時，讓貓最後抓到並咬幾秒再結束**，比突然收起玩具健康。

### 玩具分類

| 類型 | 範例 | 用途 |
|---|---|---|
| **互動玩具** | 逗貓棒、激光筆 | 主動遊戲、消耗體能、建立人貓信任 |
| 自娛玩具 | 毛絨玩具、彈跳球 | 飼主不在時的刺激 |
| 益智玩具 | 漏食球、謎題餵食器 | 心理刺激、減緩進食速度 |

### ⚠️ 激光筆警告
啟動追逐本能但**永遠沒有「抓到」的滿足感** → 長期使用可能焦慮。
若用，結束時給實體玩具讓貓抓到。

### 每日遊戲建議

| 年齡 | 每日 | 方式 |
|---|---|---|
| 幼貓（< 1 歲） | 3-5 次 × 10 分鐘 | 逗貓棒為主，消耗充沛精力 |
| 成貓（1-7 歲） | 2 次 × 10-15 分鐘 | 互動 + 自娛混合 |
| 老貓（> 10 歲） | 短而頻繁、每次 5 分鐘 | 低強度，**不要過度要求跳躍** |

### 讓遊戲更吸引貓的 4 個技巧

1. **模擬真實獵物**：不直線移動、抖動、短暫停頓、躲障礙物後
2. **輪換玩具**：對同玩具很快失去興趣，每週輪換
3. **多感官刺激**：羽毛（視）+ 沙沙聲（聽）+ 貓薄荷（嗅）
4. **預測性降低**：隨機 > 規律

### ⚠️ 玩耍攻擊（Play Aggression）

若貓玩到攻擊主人手腳：
- **立刻停止 + 無聲離開**，不要懲罰
- **永遠不要用手直接玩** — 手不是玩具
- 增加每日遊戲時間給足夠出口

## 結論

學會讀貓 = 學會避開地雷 + 看見隱形壓力 + 建立信任。
**搖尾不是搖尾、翻肚不是邀請、慢眨才是親吻**。
