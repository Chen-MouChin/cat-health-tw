# 貓咪定期健檢指南

貓咪是「藏病高手」——在野外掩藏病痛是求生本能，這使得許多疾病在家貓身上也會悄然進展直到晚期。**定期健檢是早期發現、早期治療的唯一可靠方式**。

## 健檢頻率建議

| 年齡 | 建議頻率 | 主要目的 |
|-----|--------|---------|
| 幼貓（0–1歲）| 每 3–4 週（疫苗期間）| 疫苗、驅蟲、生長監測 |
| 成貓（1–7歲）| 每年一次 | 疾病篩檢、疫苗更新、口腔評估 |
| 中老貓（7–11歲）| 每年一次（建議半年一次）| 甲狀腺、腎臟、血壓 |
| 老年貓（11歲以上）| 每半年一次 | CKD、糖尿病、高血壓管理 |

根據 AAFP 指引，7 歲以上貓咪每半年一次健檢可大幅提高早期疾病偵測率。

## 基礎健檢包含什麼？

### 理學檢查（Physical Examination）
獸醫師的雙手是最重要的工具：
- **體重與體態評分（BCS 1–9）**：肥胖或消瘦都是疾病信號
- **眼睛**：角膜、結膜、眼底（老貓高血壓可見視網膜變化）
- **耳朵**：耳疥蟲、慢性耳炎
- **口腔**：牙周病評分（台灣貓咪 2 歲以上約 70% 有不同程度牙周病）
- **淋巴結**：異常腫大可能是感染或腫瘤
- **腹部觸診**：腸道、腎臟、膀胱、腫塊
- **皮膚與毛髮**：過敏、皮膚病、外寄生蟲

### 建議加做（成貓以上）
- **全血球計數（CBC）+ 生化指數（Biochemistry panel）**：評估肝腎功能、血糖、電解質
- **尿液分析**：尿液比重、蛋白質、葡萄糖、沉渣
- **血壓測量**：特別是老貓（高血壓在老貓非常常見）
- **甲狀腺素（T4）**：7 歲以上建議每年檢測，甲狀腺亢進是老貓第二常見內分泌疾病

### 老年套餐（7 歲以上）
- 以上全部 + **SDMA**（腎臟早期損傷指標，比肌酸酐更早發現 CKD）
- **胸腔 X 光**（評估心臟大小、肺部）
- **腹腔超音波**（腎臟、肝臟、腸道形態）

## 台灣健檢費用參考

> 以下為台北市一般動物醫院之參考範圍，各院有所不同，請向各院詢價。

| 項目 | 費用參考（TWD）|
|-----|------------|
| 理學檢查 | 300–600 |
| CBC + 生化指數（12–20項）| 1,500–3,000 |
| 尿液分析 | 300–600 |
| 血壓測量 | 200–400 |
| T4（甲狀腺素）| 600–1,200 |
| SDMA（腎臟早期）| 500–1,000 |
| 胸腹部 X 光（2 張）| 800–1,500 |
| 超音波（腹部）| 1,500–3,000 |
| 全套老年套餐 | 5,000–12,000 |

## 如何讓貓咪健檢壓力更小

- **使用外出籠適應訓練**：平時將外出籠放在家中，讓貓咪自由進出
- **就醫前一晚不禁食**（非手術的健檢通常不需要空腹，抽血通常須 4–6 小時空腹，請先電話確認）
- **選擇「貓咪友善診所（Cat Friendly Practice）」**：ISFM 認證、貓犬分隔候診、低壓力處置流程
- **Feliway 噴劑**：出發前噴於外出籠，費洛蒙減輕焦慮

## 健檢結果異常怎麼辦？

不要對報告上的「偏高/偏低」感到恐慌。許多指數的臨界值解讀需要結合完整臨床表現。獸醫師會解釋哪些是需要立即處理、哪些是觀察追蹤，或建議進一步檢查。

> **免責聲明**：本文僅供參考，不構成獸醫診療建議。如有健康疑慮，請諮詢專業獸醫師。
