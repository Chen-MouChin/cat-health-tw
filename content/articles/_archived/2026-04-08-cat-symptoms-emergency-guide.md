# 貓咪這樣要去看醫生嗎？症狀緊急程度判斷指南

「這樣需要去醫院嗎？」是養貓飼主問得最多的問題之一。貓咪是天性隱藏痛苦的動物，等到明顯症狀出現，往往已不在早期。本文提供三段緊急分級，幫助你快速判斷。

---

## 🔴 立即急診（現在就去，不要等天亮）

以下症狀意味著可能在數小時內危及生命：

| 症狀 | 可能原因 |
|------|---------|
| **完全無法排尿（尤其公貓）** | 尿道阻塞，24h 內致命 |
| **呼吸困難、張口呼吸** | 心臟病、胸水、氣喘發作 |
| **嘴唇/牙齦顏色變白、紫、藍** | 缺氧，循環衰竭 |
| **突然癱瘓或後肢拖行** | 主動脈栓塞（公貓多見），血栓緊急症 |
| **癲癇發作（抽搐）超過 2 分鐘** | 腦部病變、中毒、低血糖 |
| **確認誤食毒物** | 百合花、殺蟲劑、人藥、蔥蒜大量 |
| **嚴重外傷**（車禍、高空墜落、被咬傷） | 內出血可能無外部可見 |
| **突然失明**（瞳孔極度放大、對光無反應）| 高血壓導致視網膜剝離 |
| **體溫過低或過高**（摸起來冰涼或燙熱）| 體溫調節失敗 |
| **意識不清、叫不醒** | 休克、昏迷前兆 |

> 🚗 台北市和新北市有多家 24 小時急診動物醫院，請提前查好你家附近的急診醫院（本站 [獸醫院查詢](/vets) 可搜尋）。

---

## 🟠 今天就醫（白天盡快預約，不要拖超過 24 小時）

| 症狀 | 說明 |
|------|------|
| 完全不吃不喝超過 **24 小時** | 貓咪超過 48h 不進食可能引發脂肪肝 |
| 嘔吐超過 **3 次 / 天**，或連續嘔吐 2 天以上 | 偶發嘔吐正常，頻繁代表問題 |
| 腹瀉（帶血、帶黏液、水狀）| 感染、寄生蟲、嚴重腸炎 |
| 眼睛紅腫、分泌物大量增加 | 結膜炎、角膜潰瘍 |
| 打噴嚏 + 流鼻水 + 眼屎（同時出現）| 貓上呼吸道感染（貓鼻支/卡里西）|
| 排尿時哀叫、頻繁跑廁所（母貓或輕度症狀公貓）| 膀胱炎、泌尿道感染 |
| 跛行超過 1 天 | 骨折、關節問題、外傷感染 |
| 身上有大型傷口或膿瘍 | 貓打架後的咬傷容易形成膿瘍 |
| 耳朵搔抓、搖頭、黑色分泌物 | 耳疥蟲或外耳炎 |
| 體重在 1 個月內明顯下降 | 甲亢、糖尿病、腎病、腫瘤早期徵兆 |

---

## 🟡 本週預約（可觀察 1–2 天，但不要超過一週）

| 症狀 | 說明 |
|------|------|
| 食慾輕微下降（仍有進食）| 可觀察 24h，若超過 48h 不進食升級就醫 |
| 偶爾嘔吐（每週 1–2 次）| 毛球或食速過快可能是原因，但建議確認 |
| 打噴嚏偶發（無其他症狀）| 環境刺激可能，若超過 1 週就醫 |
| 輕微眼睛分泌物增加 | 觀察是否伴隨其他症狀 |
| 抓耳偶發（無分泌物）| 觀察是否持續 |
| 喝水量明顯增加（持續超過 1 週）| 老貓需特別警惕，可能是 CKD 或甲亢早期 |
| 毛髮光澤變差或脫毛增加 | 皮膚病、過敏、壓力、甲狀腺問題 |

---

## 🟢 一般觀察（可先居家處理）

| 狀況 | 說明 |
|------|------|
| 毛球嘔吐（偶發，吐出毛球後正常）| 正常，可補充化毛膏 |
| 接種疫苗後 24h 嗜睡、食慾下降 | 正常副作用 |
| 結紮術後 1–2 天行動緩慢 | 麻醉恢復期，正常 |
| 新環境下躲藏（剛帶回家）| 正常適應行為，給牠時間 |
| 換食期間軟便 | 若只是偶發且無血，可能是換食不適 |

## 貓咪隱藏疼痛的行為密碼

貓咪進化自獵食動物，天生隱藏弱點。以下是牠在不舒服時可能出現的「隱性症狀」：

- **躲到平時不去的地方**（衣櫃深處、床底）
- **梳理突然停止**（毛髮凌亂）或**過度舔舐特定部位**
- **不願被碰觸**，甚至平時溫順的貓咪開始亂咬人
- **如廁習慣改變**（在廁所外排泄、排泄姿勢改變）
- **叫聲改變**（平時安靜突然大叫，或平時愛叫突然變安靜）
- **眼睛微微瞇起**（貓咪疼痛的面部表情，參考貓咪疼痛量表 Cat Grimace Scale）
- **不願跳躍**或**跳躍前猶豫很久**

## 就醫前的準備

到醫院前，飼主能提供以下資訊可大大幫助診斷：

1. **症狀開始時間**：幾天前？突發還是漸進？
2. **症狀頻率**：多久一次？今天發生幾次？
3. **飲食記錄**：最後一次進食是什麼時候？有沒有換食？
4. **可能的接觸**：有沒有接觸過新的植物、食物、藥物、外出？
5. **尿量/便量**：貓砂盆使用次數是否有變化？
6. **影片**（如果可以）：症狀發生時錄一段，尤其是抽搐、步態異常等間歇性症狀
