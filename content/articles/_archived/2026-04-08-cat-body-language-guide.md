# 貓咪肢體語言完整解讀指南

貓咪雖然不說話，但牠們透過身體的每個部位表達豐富的情緒和意圖。學會讀懂這些信號，是建立深厚人貓關係的基礎，也是避免誤讀而被抓傷的實用技能。

## 尾巴：最直觀的情緒指標

| 尾巴姿態 | 意義 |
|--------|-----|
| 高舉垂直，尾尖微彎 | 友善問候，開心見到你 |
| 高舉，尾尖輕顫 | 非常開心、興奮 |
| 高舉但炸毛（尾巴膨大）| 極度興奮或受到驚嚇 |
| 夾在兩腿之間 | 焦慮、恐懼、臣服 |
| 低垂、微微搖擺 | 放鬆、休息狀態 |
| 快速左右猛甩 | 煩躁、警告——停止你正在做的事 |
| 緩慢大幅搖擺 | 專注狀態（如打獵前） |

## 耳朵：情緒的精細溫度計

- **朝前豎立**：好奇、專注、友善
- **略向外轉（飛機耳）**：輕度煩躁、不確定
- **完全向後貼頭（飛機耳+壓低）**：恐懼或即將攻擊的警告
- **快速轉動**：聽到感興趣的聲音，高度警覺

## 眼睛：瞳孔和眼瞼

**瞳孔大小**（需考量光線因素）：
- **細縫瞳孔**（強光下）：放鬆或輕度侵略性
- **瞳孔放大**：興奮、恐懼、黑暗、疼痛——需結合其他信號判斷
- **全圓瞳孔**（在正常光線下）：可能代表恐懼或疼痛

**眼瞼和注視**：
- **緩慢眨眼**（Slow Blink）：表達信任和親密。你可以回應緩慢眨眼，這是跨物種的友善信號
- **直視不眨眼**：警告或挑釁
- **半瞇眼**：放鬆、滿足

**「貓咪之吻」實驗**：在貓咪放鬆時，緩慢眨眼，等待牠回應。許多貓會以慢眨回答，這是純粹的社交聯繫行為。

## 姿勢與整體體態

### 放鬆信號
- 完全趴著，四肢藏於身下（麵包姿）：完全放鬆、有安全感
- 側躺露出腹部：**極度放鬆和信任**（但不一定是邀請觸摸！）
- 慢慢甩尾、眼睛半閉

### 恐懼與防禦
- 身體壓低、重心後移、耳朵後壓
- 毛髮豎立（炸毛）：讓自己看起來更大
- 弓背側對攻擊者（同時讓自己看起來更大）

### 攻擊前警告
**貓咪在攻擊前通常會發出多個警告信號，了解這些可以避免被傷**：
1. 尾巴快速抽打
2. 皮膚顫動（背部皮膚微微抽動）
3. 耳朵後壓
4. 瞳孔放大
5. 低沉嘶吼或哈氣

如果看到這些信號，停止你的動作，給貓咪空間和出口。

## 常見誤讀

**翻肚不代表「摸我肚子」**：對大多數貓咪，露出腹部是信任的表示，但不是觸摸邀請。貿然觸摸腹部可能立刻引發「摸了就咬」的反射——這是本能防禦，不是壞貓。

**搖尾巴不等於開心**：貓咪搖尾巴和狗狗的意義完全相反。搖尾（特別是快速甩動）通常代表煩躁。

**凝視不是友善**：正面直視在貓咪社交中是挑釁信號。和貓咪建立眼神接觸應以慢眨、移開視線，而非盯著看。
