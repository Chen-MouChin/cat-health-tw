# 貓咪安寧照護

當貓咪確診末期疾病（晚期 CKD、淋巴瘤、癌症），或治癒已不再是可行選項時，照護的重心從「戰勝疾病」轉向「舒適度過剩餘時光」。這就是**獸醫安寧照護（Veterinary Palliative/Hospice Care）**的核心精神。

## 安寧照護 ≠ 放棄

很多飼主誤解「安寧」意味著不再積極治療。事實上，安寧照護是：
- **積極管理疼痛和不適症狀**
- 讓貓咪在熟悉的環境中度過時光
- 維持盡可能高的生命品質（Quality of Life, QoL）
- 支持飼主的心理需求

## 生命品質評估

**Ohio State University 的 HHHHHMM 量表**是常用的評估工具（英文縮寫），請獸醫幫助評分：

| 項目 | 評估方向 |
|-----|--------|
| Hurt（疼痛）| 是否能有效控制疼痛？ |
| Hunger（飢餓）| 是否能維持基本進食？ |
| Hydration（水分）| 是否有足夠水分攝取？ |
| Hygiene（清潔）| 皮膚和毛髮是否保持清潔？ |
| Happiness（幸福感）| 是否仍表現出享受的行為？ |
| Mobility（活動力）| 是否能自行移動至貓砂盆、食盆？ |
| More good days than bad（好日子 > 壞日子）| 整體評估 |

當「壞日子」明顯多於「好日子」，這是需要與獸醫討論的重要信號。

## 常見末期疾病的居家舒適措施

### CKD 末期（Stage 4）

- **皮下補液**：居家執行的最有效舒適措施，稀釋毒素、維持水分
- **磷結合劑**：混入食物，維持口感可接受的低磷飲食
- **止吐藥**：控制噁心嘔吐，維持進食意願
- **食慾促進劑**（如 Mirtazapine）：需獸醫評估和處方

### 癌症照護

- **疼痛管理**：Buprenorphine、Gabapentin，需獸醫調整劑量
- **舒適臥鋪**：記憶泡棉、加熱墊（確保不過燙）
- **讓貓咪在喜愛的地方休息**：不強迫移動

### 一般舒適措施

- 降低障礙：貓砂盆邊緣低、食碗和水碗放在容易到達的位置
- 保暖：末期貓咪體溫調節能力下降，需要溫暖環境
- 輕柔陪伴：維持熟悉的聲音、氣味、觸碰

## 安樂死的倫理考量

在台灣，獸醫安樂死是合法的，當貓咪的生命品質持續惡化、痛苦無法有效緩解時，這可能是最具愛心的選擇。

**應考慮安樂死的時機**：
- 疼痛無法有效控制
- 無法自行喝水、進食
- 完全喪失移動能力
- 呼吸困難
- 連續多天表現出痛苦跡象

這是極其艱難的決定，沒有「完美的時機」。許多獸醫認為：**早一天比晚一天好**——讓貓咪在尚存一點尊嚴時離開，優於等到完全絕望再做決定。

## 飼主的心理支持

照護末期寵物是沉重的心理負擔。台灣有以下資源：
- 部分動物醫院提供「寵物失去輔導」
- 線上社群（如「貓咪過橋關懷社群」Facebook 群組）
- 心理諮商（寵物失喪 grief 是真實的哀傷，值得認真對待）
