# 貓咪環境豐富化指南：台灣公寓版完整規劃

台灣有超過 200 萬戶家庭飼養貓咪，其中絕大多數是室內貓。然而「有吃有住」不等於「生活品質好」——在一個缺乏刺激的環境中，貓咪會出現壓力行為、肥胖，乃至各種疾病。環境豐富化（Environmental Enrichment）是解決這一問題的核心工具。

---

## 為什麼室內貓需要環境豐富化？

貓咪的祖先是獨居的掠食者，每天需要花大量時間追蹤、潛伏、狩獵獵物。現代室內生活讓牠們的本能需求幾乎全部被剝奪。

根據 **ISFM（國際貓科醫學會）** 的環境需求指引，缺乏豐富環境的貓咪容易出現：

- **壓力誘發的疾病**：貓下泌尿道症候群（FLUTD）、反覆性膀胱炎
- **行為問題**：亂尿尿、過度梳毛、攻擊行為
- **肥胖**：活動量不足，加上自由取食，是台灣室內貓肥胖的主要原因
- **慢性焦慮**：對突發聲音過度反應、躲藏時間過長

> International Cat Care（icatcare.org）指出，許多飼主誤以為貓咪「在睡覺」就代表牠很放鬆；但真正健康的貓咪應該有固定的活躍時段，表現出探索、玩耍等主動行為。

---

## 5 個核心需求

### 1. 獵食機會（Hunting Opportunities）

貓咪天生偏好「為食物付出努力」。長期使用固定食碗會讓牠們失去精神刺激。

**實作方式：**
- **益智餵食器**（Puzzle Feeder）：將乾糧放入迷宮型容器，讓貓撥弄才能吃到
- **散糧遊戲**：把乾糧撒在地板上或藏在紙捲筒裡
- **定時少量多餐**：模仿自然界「一天獵到多隻小型獵物」的模式

### 2. 垂直空間（Vertical Space）

高度對貓咪來說代表安全感和地位。ISFM 建議室內貓必須有可以「往上走」的路徑。

**台灣公寓實作方案：**

| 方案 | 費用估算（NT$） | 說明 |
|------|--------------|------|
| 落地貓跳台（MEOW BOY、MYZOO 等）| 1,500–4,000 | 大多數公寓最快的解決方案 |
| 牆面層板（宜家 LACK 系列改裝）| 300–800/片 | 需鎖牆，承重需確認 |
| 貓牆系統（MYZOO 或 Catastrophic Creations）| 5,000–20,000 | 完整的高空走道，最理想 |
| 書櫃 / 冰箱頂部 | 0（現有家具）| 清空後加防滑墊即可 |

台灣品牌 **MYZOO**（米茲設計）和 **MEOW BOY** 均提供適合小坪數公寓的模組化系統，在 momo、PChome 和品牌官網均有販售。

### 3. 藏身處（Hiding Spots）

藏身處讓貓咪在感到焦慮時有「逃到安全地帶」的選擇。沒有出口的壓力會直接轉化為攻擊性或疾病。

**低成本方案：**
- 紙箱側開一個洞，內鋪舊毛毯（成本：0）
- 布製帳篷式貓屋（NT$200–600）
- 確保每個房間至少有一個貓咪可以獨處的角落

### 4. 抓抓能力（Scratching Outlets）

抓抓是貓咪的本能行為——標記領域、伸展肌肉、保持爪子健康。**禁止抓抓不可行，只能引導到合適的地點。**

ASPCA 建議每個家庭至少提供 **2–3 個不同材質的貓抓板**，放置在貓咪常活動的地方（不要藏在角落）。

| 材質 | 台灣常見品牌 | 費用（NT$）|
|------|------------|-----------|
| 瓦楞紙（平躺型）| 喵行者、各大賣場自有品牌 | 100–300 |
| 麻繩（直立柱型）| MEOW BOY 貓跳台內建 | 300–1,500（含跳台）|
| 地毯材質（斜面型）| 多數寵物店 | 200–500 |

### 5. 嗅覺刺激（Olfactory Enrichment）

貓的嗅覺是人類的 14 倍，提供新的氣味是最被低估的豐富化方式。

**實作方式：**
- **貓薄荷**（Catnip）：約 60–70% 的貓有反應，灑在玩具上或貓抓板旁
- **木天蓼**（Matatabi）：對貓薄荷無反應的貓，大多對木天蓼有強烈反應；台灣寵物店和 momo 均可購得（NT$100–300/包）
- **紙袋、購物袋**：新鮮的外部氣味讓貓探索良久
- **隱藏零食**：用紙捲或紙盒包住零食，讓貓自己拆開

## 互動玩耍：頻率與技巧

ISFM 和 ASPCA 均建議：**每天至少 2 次、每次 10–15 分鐘的主動互動玩耍**，對保持貓咪的身心健康至關重要。這對特別活躍的年輕貓（1–7 歲）尤為必要。

### 逗貓棒的正確使用方式

1. **模仿獵物動作**：不規則移動、躲到桌腳後、緩慢爬行再突然衝刺
2. **讓貓「成功抓到」**：每次玩耍必須讓貓至少抓住幾次，帶來成就感
3. **冷卻期**：玩耍結束前讓獵物「越來越慢」，模仿筋疲力盡的獵物，不要突然停止
4. **玩完後給零食**：完成「狩獵 → 進食」的完整循環，有助於身心滿足
5. **輪換玩具**：貓咪容易對固定玩具失去興趣，每隔幾天換一款

> 注意：雷射筆因為永遠無法「抓到」，長期使用可能造成挫敗感。若使用，務必在最後用逗貓棒或零食收尾。

## 低成本 DIY 方案

環境豐富化不需要花大錢：

| DIY 方案 | 材料 | 成本 |
|---------|------|------|
| 紙箱城堡 | 超商紙箱 + 美工刀 | 0 |
| 零食迷宮 | 衛生紙捲筒 + 紙板 | 0 |
| 嗅探墊 | 舊毛巾剪條 + 橡皮筋 | 0 |
| 窗台觀景台 | 現有窗台 + 防滑墊 | NT$50–100 |
| 移動獵物玩具 | 羽毛 + 釣魚線 + 舊筷子 | NT$50 |

**紙袋**（無繩）和**衛生紙捲筒**是最便宜的探索玩具——放在地板上讓貓自己研究，效果往往不遜於市售玩具。
