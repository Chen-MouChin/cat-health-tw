# 新貓到家前的安全檢查清單

## 電線和電氣

- [ ] 電線束起或用保護套包住（貓咪愛啃電線）
- [ ] 電源延長線不要放在地面
- [ ] 加熱設備（電毯、暖爐）有安全關閉機制

## 有毒化學品

- [ ] 清潔劑、漂白水、消毒水放在有門的柜子裡
- [ ] 廁所蓋子關閉（含有清潔錠的馬桶水有毒）
- [ ] 洗衣精膠囊放置在貓咪無法取得的高處（高濃度有毒）

**精油特別警告**：
許多常見精油對貓咪**高度毒性**，包括：茶樹油、薰衣草（高濃度）、尤加利、柑橘類精油。
不要在家中使用擴香器或精油薰香，貓咪的肝臟無法代謝這些化合物。

## 食物危險

- [ ] 蔥蒜類（洋蔥、大蒜、韭菜）放在密閉容器
- [ ] 巧克力、葡萄/葡萄乾不能讓貓取得
- [ ] 含木糖醇的食品（無糖口香糖）放置安全
- [ ] 垃圾桶有蓋（咖啡渣、茶包、骨頭碎片）

## 物理危險

- [ ] 洗衣機和乾燥機每次使用前檢查是否有貓咪躲入
- [ ] 冰箱開關門注意貓咪是否在附近
- [ ] 高處窗台有防墜網
- [ ] 陽台欄杆間距小於 8 cm（幼貓可能卡住）

## 小物件吞食危險

- [ ] 縫衣針、線、橡皮筋放在抽屜裡
- [ ] 耳機線、USB 線束起
- [ ] 藥品（人用和寵物用）放在有鎖的抽屜或高處

**特別注意**：線狀異物（線、橡皮筋、緞帶）對貓咪特別危險。貓咪舌頭有倒刺，一旦含進去很難吐出，可能造成腸道穿孔。

## 逃跑防護

- [ ] 紗窗或窗戶鎖（貓咪能推開未鎖緊的窗戶）
- [ ] 大門進出時確認貓咪位置
- [ ] 訪客告知不要開門放跑貓咪

## 貓咪喜歡鑽的藏身處

新貓剛到家時極可能躲藏，確認以下位置是否安全：
- [ ] 沙發底部是否有釘子或尖銳突出物
- [ ] 牆壁洞口是否封住
- [ ] 冰箱後面的間隙
