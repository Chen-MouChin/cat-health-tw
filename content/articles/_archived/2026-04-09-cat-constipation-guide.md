# 貓咪便秘：症狀識別與處理

貓咪正常的排便頻率是每日 1-2 次，最長不超過 2 天。若超過 2-3 天沒有排便，應開始注意是否發生便秘。

## 症狀識別

**早期便秘**：
- 進出貓砂盆次數增加但排便少
- 蹲坐很久才排出少量乾硬糞便
- 糞便比平常硬且乾燥

**中度便秘**：
- 超過 2 天無排便
- 明顯用力但無法排出
- 食慾略下降

**嚴重便秘（需立即就醫）**：
- 超過 3 天無排便
- 腹部觸摸感覺堅硬
- 嘔吐（毒素積累）
- 完全不進食

## 常見原因

| 原因 | 說明 |
|-----|-----|
| 脫水/飲水不足 | 最常見，乾食為主的貓咪特別容易 |
| 飲食纖維不足或過多 | 失衡影響腸道蠕動 |
| 毛球積累 | 毛球阻礙腸道 |
| 缺乏運動 | 老貓、肥胖貓咪 |
| 直腸異物 | 誤食骨頭碎片 |
| 關節炎 | 蹲下排便太痛，貓咪避免 |
| 藥物副作用 | 部分止痛藥、抗組織胺 |
| 神經系統問題 | 脊椎損傷影響腸道蠕動 |
| 巨結腸症 | 慢性便秘的晚期結果 |

## 居家緩解方法（輕度便秘）

**增加水分**（最重要）：
- 立刻轉換為濕食或在乾糧中加溫水
- 更換流動飲水機
- 確保水碗在多個位置

**纖維補充**：
- 南瓜泥（罐頭，無糖無鹽）：每餐加 1-2 茶匙
- 貓草：天然纖維
- 亞車前子殼（Psyllium husk）：少量混入食物

**輕柔腹部按摩**：
- 以指尖輕柔按摩貓咪腹部，順時針方向
- 每次 2-3 分鐘，每日 2 次
- 貓咪若不適應就停止

**增加活動量**：
- 逗貓棒遊戲增加腸道蠕動

## 何時就醫

以下情況不適合等待，需要獸醫介入：
- 超過 3 天無排便
- 有腹痛症狀
- 嘔吐或精神不振
- 居家措施 24 小時後無改善

獸醫治療選項：灌腸（注意：絕不可自行使用人用灌腸劑，對貓有毒）、口服軟便劑、靜脈補液。

## 巨結腸症（Megacolon）：長期便秘的代價

若貓咪反覆發生嚴重便秘被忽視，結腸可能因長期擴張而喪失蠕動能力，形成**巨結腸症**——這幾乎是不可逆的疾病，需要終生管理，嚴重時需要手術切除部分結腸。

預防巨結腸症的關鍵：
- 早期積極處理便秘
- 充足飲水
- 長期使用軟便劑（需獸醫指示）
