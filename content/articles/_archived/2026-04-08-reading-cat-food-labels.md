# 如何看懂貓咪飼料成分標示

台灣市售的貓咪飼料琳瑯滿目，標榜「高蛋白」「無穀」「人食等級」的廣告用語充斥，但真正判斷飼料品質的依據是**成分標示**，而非行銷文字。

## 成分列表的排序邏輯

根據台灣《寵物食品管理辦法》（參考 AAFCO 規範），原料必須**依重量由高至低排列**（以未加工前的濕重計算）。

這產生一個重要的「含水稀釋效應」：雞肉的含水量約 70%，去水後的實際蛋白質遠低於在列表中的位置所暗示的比重。若您看到：

> 雞肉、燕麥、豌豆蛋白、雞肉粉……

「雞肉粉」雖排名靠後，但它是乾燥濃縮原料，實際蛋白質貢獻往往高於排名更前的「雞肉」。

## 保證成分分析

飼料外包裝通常標示四項保證值（Guaranteed Analysis）：

| 項目 | 意義 | 成貓建議（乾基） |
|-----|-----|--------------|
| 粗蛋白 | 動物性或植物性蛋白質總量 | ≥ 40%（乾基） |
| 粗脂肪 | 脂肪含量（能量密度指標）| 15–25% |
| 粗纖維 | 消化纖維 + 不消化纖維 | < 5% |
| 水分 | 決定保存期與熱量密度 | 乾糧 < 12%，濕食 > 70% |

### 乾基換算（Dry Matter Basis）

比較乾糧與濕食時，必須換算到同一基準才公平：

```
乾基蛋白質 = 標示蛋白質% ÷ (100 - 水分%) × 100
```

例：濕食標示蛋白質 10%，水分 78% → 乾基蛋白質 = 10 ÷ 22 × 100 = **45.5%**，高於多數乾糧。

## 灰分（Ash）是什麼？

灰分是飼料燃燒後剩餘的礦物質總量，主要是鈣、磷、鎂等。  
貓咪泌尿道健康飼料通常要求**灰分 < 8%**（乾基）；灰分過高代表原料品質較差（骨粉比例高），礦物質來源粗劣。

## 常見行銷話術辨識

| 話術 | 實際意義 |
|-----|--------|
| 「無穀（Grain-free）」| 不含小麥/玉米，但可能含豌豆、馬鈴薯等澱粉，貓咪依然不需要大量碳水 |
| 「人食等級」| 台灣無此法規定義，屬行銷用語 |
| 「天然防腐劑」| 維生素 E（混合生育醇）是合法且優質的選擇；需辨別是否確實標示來源 |
| 「全肉配方」| 需確認蛋白質來源（肉vs副產品vs植物蛋白）比例 |

## 如何找到可靠的飼料

1. **查看 AAFCO 或 FEDIAF 完整營養聲明**：確認是「經由配方計算」還是「飼餵試驗驗證」——後者更嚴格
2. **避免「副產品」排在前三名**（心、肝除外，這些是高蛋白優質副產品）
3. **比較多款飼料的乾基蛋白質**，選擇 > 40% 的選項
4. **諮詢獸醫**：針對有特殊需求的貓咪（如 CKD、泌尿道問題）選擇處方飼料
