# 貓健康站寫作規範

目標讀者：台灣一般飼主，貓可能正在生病，讀者焦慮、時間少、會拿文章去問獸醫。
目標語氣：一位讀過原始指引、講話直接、不賣東西的資深飼主。不是教科書，也不是部落客。

## 一、開始寫之前

1. 先列出這篇會用到的每一筆來源，確認 `content/references/citations.json` 有對應 key。沒有 key 的來源先加進去，或不寫那個數字。
2. 讀 `research/inbox/article-audit-2026-09-06.md` 裡該篇的「必修」欄（若存在）。
3. 查同主題其他文章的數字（減重速度、水量、疫苗時程、法規），**不可與既有文章矛盾**。矛盾時以有出處的一方為準，並同時修另一篇。

## 二、固定結構

醫療類文章依序包含以下區塊。行為、入門、法規類可省略「何時就醫」但其餘保留。

```
# 標題（說清楚疾病或問題，不用問句、不用「完整指南」）

導言一段：這是什麼、為什麼飼主該在意、這篇能幫你做什麼決定。三到五句。

## 哪些情況建議請獸醫看看
（症狀清單，每條一行，寫具體可觀察的現象，不寫「異常」。語氣是建議：「建議請獸醫看看」「盡早聯絡獸醫」，不寫「立刻」「馬上」「現在就出門」「不要等」）

## 30 秒重點
（三條。每條一句主張加一句理由。這是全文唯一允許用粗體標題的清單）

## 正文各節
（用讀者的問題當標題：「為什麼公貓特別容易？」而不是「病理機制」）

## 居家能做的事
（清單，每條動詞開頭）

## 常見問題
（三到五題，用飼主真的會問的句子。每題答案兩到四句）

## 參考文獻
（由 build.py 從註腳自動產生，正文不手寫這節）

> 免責聲明（由 build.py 統一插入，正文不手寫）
```

## 三、引用規則

- **每一個數值、劑量、比例、分期標準、年齡門檻，句尾必帶註腳** `[^KEY]`，KEY 是 citations.json 的 key。例：`母貓 6 個月前結紮可降低乳腺腫瘤風險 91%[^OVERLEY-2005]。`
- 沒有來源的數字不寫。寧可寫「多數老貓」也不寫「約 40% 的老貓」而沒有出處。
- 「研究顯示」「專家建議」「獸醫普遍認為」是禁語。寫出是誰、哪一年。
- 引號只用於逐字原文。轉述國外指引的中文一律用間接引述，不加引號。
- 台灣費用、補助、法規條號同樣要有來源（動保處公告、法規資料庫、醫院公開價目），標明查詢日期。
- 來源之間有分歧時，兩邊都寫，說明差在哪裡，不自己下結論。

## 四、品牌與商品

- 飼料、藥品、用品一律用通用名稱：腎臟處方飲食、低碘處方飲食、含 selamectin 的外用滴劑、合成貓臉部費洛蒙、含蛋白酶的酵素清潔劑。
- 不列品牌比較表、不寫價格區間表、不寫購買通路。
- 藥物寫成分名。犬用藥在貓為標示外使用時必須註明。
- 唯一例外：讀者非知道商品名否則會買錯而造成危險（例如「含 permethrin 的犬用驅蟲劑對貓有毒」）。此時商品名出現一次，目的是排除，不是推薦。

## 五、去 AI 痕跡

改稿時逐一檢查，全部命中才算過：

**句型**
- 刪「不只是 X，更是 Y」「X 不是 Y，而是 Z」的對比修辭，直接說 Z。
- 防禦句型黑名單：「我們不是」「不假裝」「並非」「而不是」「不靠」「不憑」「不替讀者」「我們無法」「我們做不到」。寫成正面陳述，說明是什麼、怎麼做。lint 的 `defensive` 規則會擋，網站手寫頁面用 `python scripts/lint_articles.py --pages` 檢查。
- 刪段尾金句。一段的最後一句必須是資訊，不是感想。
- 刪「值得注意的是」「重要的是」「這意味著」「換句話說」「總而言之」「毫無疑問」開頭。
- 三個一組的排比（「安全、健康、快樂」）拆成真正需要的項目數。
- 「——」「—」「→」「≠」全部改回句號、逗號或完整句子。箭頭只允許出現在流程表格內。
- 「讓我們」「一起來」「你有沒有想過」等對讀者喊話的句子刪除。

**格式**
- 標題不加 emoji。內文不用 emoji，也不用 🚨‼️ 這類急迫符號。
- 一段內粗體最多一處。粗體用在讀者做決定需要的那個詞，不是用來強調語氣。
- 清單項目要是完整意思，不是三個字的片語。連續三個清單之間至少要有一段散文承接因果。
- 表格用來比較，不用來排版。一個欄位只有一兩個字的表格改成清單。
- 不用「✅❌⚠️」當項目符號。

**語氣：建議，不渲染急迫**
- 適用範圍：醫療內容裡「讀者該怎麼做」的句子（就醫時機、症狀處置）。品種的遺傳疾病風險、法規限制這類資訊標示不在此限，可以用警示色與圖例。
- 本站不告訴讀者「立刻就醫」，而是「建議請獸醫看看」「盡早聯絡獸醫」「打電話問獸醫」。判斷急迫程度是獸醫的事。
- 刪「立刻」「馬上」「現在就出門」「不要等天亮」「衝急診」「緊急狀況」「致命」這類字。寫狀況本身，加上找獸醫的入口（`../vets.html`、`?only24h=1`）就夠。
- 不用紅色、驚嘆號、🚨‼️ 渲染。

**用詞**
- 「絕對」「永遠」「一定」「保證」「所有」「任何」出現時停下來想：這是醫學上真的沒有例外，還是語氣加強？後者刪掉。安全警告用「不要」「切勿」。
- 「完整指南」「全解析」「一次搞懂」「終極」不進標題。
- 「毛孩」「喵星人」「主子」「鏟屎官」不用。用「貓」「貓咪」「飼主」。
- 「八九不離十」「中招」「燒光」這類口語在醫療段落換成中性用語。
- 「牠」指貓，「它」指物。

**內容**
- 每篇至少一段是因果解釋，說明「為什麼」，不能整篇都是「怎麼做」的清單。
- 不寫沒有出處的台灣統計（「台灣 30% 的貓」）。
- 不寫「台灣飼主最常犯的錯誤」這類無法查證的斷言，除非有調查來源。

## 六、台灣在地化

每篇至少落實兩項，且必須有來源：

- 法規：條號、主管機關、罰則，附法規資料庫連結與查詢日期
- 費用：寫「估計」或「參考」，說明依據（幾家醫院公開價目或動保處公告）
- 補助：縣市、年度、金額，註明「以當年公告為準」
- 氣候：夏季高溫、全年跳蚤、颱風季停電等對貓的具體影響
- 就醫：連到 `../vets.html`，急症文加 `?only24h=1`
- 用語：貓砂、飼料、結紮、晶片、動保處。不用「貓糧」「絕育」等非台灣慣用詞

## 七、frontmatter

```yaml
---
title: "標題（與 H1 相同）"
slug: kebab-case-english
date: YYYY-MM-DD
category: 健康 | 行為 | 飲食 | 入門 | 環境 | 階段
tags: [三到六個]
description: "給搜尋結果看的一句話，80 到 120 字，含主要症狀或問題"
sources:
  - "與 citations.json key 對應的來源描述"
cover_image: images/articles/{slug}.jpg
find_vet: cat_only | emergency | both
quality: draft
last_reviewed: null
related: [slug-a, slug-b]
---
```

- 內部連結一律相對於 `frontend/articles/`：同層文章寫 `slug.html`，站內其他頁寫 `../vets.html`。**不可用 `/vets.html` 開頭的絕對路徑**，站台部署在子路徑下會 404。
- 不在正文放 HTML 區塊。「找獸醫」按鈕用 `find_vet` 欄位。

## 八、交稿前自檢

先跑自動檢查，再做人工項目：

```bash
python scripts/lint_articles.py --slug <slug>        # 單篇，列出每個 FAIL/WARN
python scripts/lint_articles.py                      # 全站摘要表
python scripts/lint_articles.py --fix                # 自動修絕對路徑與殘留 HTML 註解
```

FAIL 必須清零才算交稿。WARN 是提醒，處理不了要在回覆裡說明原因。
`.claude/settings.json` 已註冊 PostToolUse hook：每次 Edit/Write 文章後自動跑單篇 lint，有 FAIL 會把結果回饋給你，修完再繼續。

人工項目，任一項不過就不算完成：

- [ ] 每個數字後面有 `[^KEY]`，且 KEY 存在於 citations.json
- [ ] 文中沒有品牌名、商品名、價格表、購買通路
- [ ] 沒有「——」「→」「≠」，標題沒有 emoji
- [ ] 沒有引號包住的中文轉述
- [ ] 用 grep 確認：`絕對|永遠|一定能|保證|毫無疑問|值得注意|讓我們|不只是` 零命中，或每個命中都有醫學理由
- [ ] 與同主題文章的數字一致（減重速度、水量、疫苗時程、晶片、狂犬病）
- [ ] 有「哪些情況建議請獸醫看看」「30 秒重點」「常見問題」三節
- [ ] 用 grep 確認：`立刻|馬上|現在就|不要等|衝急診|緊急` 零命中。本站不替讀者判斷急迫程度，只建議找獸醫評估
- [ ] 內部連結是相對路徑，且至少連 2 篇相關文章
- [ ] 導言能回答「這篇幫讀者做什麼決定」
- [ ] 讀一遍，找出任何一段的最後一句是感想而非資訊，刪掉

## 九、範本文章

寫新文章前先讀這三篇，它們分別在結構、引用、急症呈現上最接近目標：

- `2026-04-19-cat-toxic-substances-taiwan.md`：句內引用密度
- `2026-04-08-male-cat-urethral-obstruction.md`：急症結構與時間軸

它們各自仍有審核報告列出的問題，模仿結構，不要複製缺點。
