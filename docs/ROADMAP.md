## 階段 D：成長

不排時程，依流量與回饋決定順序。

- 獸醫院頁：地圖內嵌（需 API key）、依症狀推薦專科、飼主回報 24 小時資訊是否正確的機制
- 品種圖鑑：台灣常見 10 種補中文描述與台灣化資訊（價格、領養管道、常見病），`data/breeds/manual_overrides.json`
- 台灣在地內容：各縣市結紮補助年度整理頁、寵物保險條款比較頁（無利益關係）
- 讀者贊助（Ko-fi）：流量起來後在文章尾加連結，不擋內容
- 文章重審機制：reviewed 滿 12 個月自動回到待審佇列（工作檯加一個篩選）
- 搜尋改進：同義詞（腎衰、腎病、CKD）、症狀導向入口
- 分析：決定是否加隱私友善的流量統計（Plausible 或 GoatCounter），或只用 Search Console
- 互動工具（視覺改版第二階段）：互動式急症判斷、貓年齡換算、每日飲水量、IRIS 慢性腎病分期計算、文獻與獸醫院分布的互動圖表、捲動敘事。方向見 `docs/design-prompts.md` 5-3

## 不做

- 商品比價（已移除，見 `research/archived-features.md`）
- 業配、聯盟行銷、品牌推薦
- 評分系統（沒有可信的資料來源）
- 引用 Frontiers 期刊
- 任何需要伺服器常駐的功能，維持純靜態
- 站內導航、路線規劃、車程估算（「導航」按鈕只把地址交給 Google 地圖）
