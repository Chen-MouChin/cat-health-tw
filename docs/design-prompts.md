# 視覺設計需求書與委託 Prompt（第二版）

更新：2026-09-29。風格定案：全站主調是「溫暖插畫 × 公共服務」，專業文獻區用「醫學期刊」排版，並加入動態。內容：一份設計需求書、首頁 prompt、五個頁面延伸 prompt、兩組情緒板。第一版的五個風格方向已由這一版取代，要看請查 git 歷史。

## 怎麼用

- **找設計師**：傳「設計需求書（第二版）」。第十點的畫布連結如果對方打不開，請從畫布的 Share 選單開放連結；第十一點的時程與預算請自己填。Logo 檔在 repo 的 frontend/images/logo/，記得一起附。
- **用 AI 產生介面**：先貼「首頁」prompt，再依序貼延伸 prompt：文章頁、獸醫院查詢、學術文獻庫、文章列表、元件表與動態規格。同一段可以多跑幾次挑最好的。
- **先看氛圍**：情緒板 prompt 貼到 Midjourney 或其他生圖工具，只拿來抓色彩和質感；生圖工具畫不好中文字。--ar、--style 是 Midjourney 專用參數，其他工具請刪掉。
- **回收成果**：照需求書第九點的交付物要。比較時看四件事：半夜急診能不能十秒找到醫院並撥號、長文章好不好讀、文獻區有沒有期刊的可信感、動態是加分而不是干擾。

## 一、設計需求書（第二版）

```text
【貓健康站 網站視覺改版 設計需求書（第二版，2026-09-29）】

零、這一版的重點
- 風格定案：全站主調是「溫暖插畫 × 公共服務」；專業文獻區（學術文獻庫、文章的註腳與參考文獻）用「醫學期刊」排版。
- 網站不能再像現在這麼素：要有插畫、色塊與動態，例如數字跑碼、脈搏線動畫。這次先設計動態語言與第一批動畫；互動工具（急症判斷、計算工具、互動圖表）列為第二階段，先畫方向草圖。
- 主色定為深苔綠 #3b6a50。

一、網站是什麼
貓健康站是台灣的貓健康知識庫，純靜態網站（GitHub Pages）。目前有 56 篇醫療科普文章、全台 22 縣市 2,001 家動物醫院查詢（可定位找附近、篩 24 小時急診與貓專科）、109 筆學術文獻、68 種品種圖鑑。
定位是「貓生病了第一個想到的網站」：每個數字都附註腳，回溯 ISFM、AAFP、IRIS、WSAVA 等原文；不業配、不接聯盟行銷，靠 Google AdSense 維持。

二、誰會用
1. 半夜急診的飼主：貓尿不出來、呼吸急促、抽搐或誤食。拿著手機、單手、很慌，要在十秒內找到附近的 24 小時醫院並打電話。
2. 照顧慢性病老貓的飼主：慢性腎病、糖尿病、甲狀腺亢進。會讀長文章、看表格、點註腳查出處。
3. 新手飼主：想了解疫苗、結紮、飲食、行為，隨意瀏覽。
4. 想查原始文獻的讀者：獸醫系學生、研究型飼主。會進文獻庫看指引與研究的書目、摘要與原文。
手機是主要流量，請從 390px 寬開始設計。

三、想傳達的感覺
親切、清楚、可信，而且有生命力。新手一進來不害怕，急診的人十秒內找到醫院，想查證的人在文獻區看到期刊等級的嚴謹。不要像醫院官網一樣冷，不要像寵物用品電商一樣吵，也不要像現在一樣素。

四、品牌資產（不可改）
- Logo：貓耳記號＋手繪字標「貓健康站」（字型為貓啃什錦黑）＋金色心電圖脈搏線。SVG 檔另附。
- 品牌色：奶油米 #f9f6f0、近黑 #1d1d1f、苔綠 #5b8a6e、金 #b8860b。可以調整比例與明度，但這四色要認得出來。
- 定 Logo 時記下的取捨：手繪字標的專業感最弱，醫療內容頁要靠版面把可信度補回來。

五、風格定案
5-1　主調：溫暖插畫 × 公共服務
骨架學英國政府網站 GOV.UK 與 NHS：
- 大字、單欄為主、清楚的標題層次。手機 H1 約 28px，內文 17 到 18px、行高 1.75 到 1.8。
- 每頁一個主要動作；內文連結加底線；鍵盤焦點框用明顯的金黃色外框。
- 急診區塊學 NHS 的醒目寫法：紅色區塊、條列，一眼看完。但不寫就醫建議（例如「不要等天亮」），只放常見狀況與找 24h 急診的入口，避免讓人一有狀況就跑急診。
溫度來自插畫與色塊：
- 圓角：卡片 16 到 20px，按鈕大圓角或全圓。
- 用品牌色的淺色色塊當區塊底：淺苔綠 #e7efe9、淺金 #f6ecd2、奶油米 #f9f6f0。
- 單線條貓插畫：線寬一致，用近黑或苔綠；不要寫實、不要 3D、不要漸層。
- 文案語氣親切，用飼主會說的話。
兩者衝突時：
- 醫療內容（急診、文章內文、醫院清單、表格）以清楚為準，不放插畫、不加裝飾。
- 首頁主視覺、分類入口、空狀態（找不到、定位被拒、範圍內沒有醫院）、404、頁尾可以放插畫與色塊。
- 卡片可以用，但要有清楚的邊界與足夠對比，不能只靠陰影區分。
顏色分工：
- 奶油米 #f9f6f0 當底，卡片白色；文字近黑 #1d1d1f。
- 深苔綠 #3b6a50 是主色：連結、主按鈕、選取狀態。
- 金色 #b8860b 只用在 Logo 脈搏線與小記號；需要金色的文字用 #8a6408。
- 紅色 #b93a2e 只留給急診。
字體：
- 全站用系統黑體（蘋方、微軟正黑體、Noto Sans TC）。
- 首頁主標等少數品牌時刻，可以用圓體風格的字（例如 jf 粉圓體），只能子集化。

5-2　專業文獻區：醫學期刊
適用範圍：學術文獻庫、文章頁的註腳與參考文獻，以及之後的文獻詳細頁。
- 標題用思源宋體（子集化）；章節編號；細橫線分隔；欄目名稱與標籤用字距加寬的小字。
- 文獻卡片用書目格式：作者、年份、題名、期刊、卷期頁碼、DOI 或 PMID，加上審核狀態、能不能免費讀原文、被幾篇文章引用、中文摘要。
- 註腳：句內上標編號；桌機放在右側旁註，手機點了才展開。
- 數字一律用等寬數字。
- 導覽列、色票、圖示沿用全站，只在排版與字體上切換：讓人感覺進了資料室，但還是同一個網站。這一區不用紅色，紅色只留給急診。

5-3　動態與互動
第一階段（這次要設計）：
- 數字跑碼：首頁與文獻庫的關鍵數字（22 縣市、2,001 家獸醫院、56 篇文章、109 筆文獻、68 種品種；文獻庫的總計、已核對、可免費讀原文）進入畫面時從 0 跑到實際數字，約 1 秒，只跑一次。數字由網站資料自動產生，不能寫假數字。
- 脈搏線：Logo 與章節記號的金色心電圖線，首頁載入或區塊出現時「畫出來」一次。
- 插畫小動作：首頁與空狀態的貓插畫，很慢、很小的眨眼或甩尾巴。
- 微互動：按鈕按下的回饋、卡片滑過微微浮起、篩選切換的過場、撥號與複製後的確認。
- 獸醫院：定位中的動畫（雷達或脈搏），結果依距離依序出現。
第二階段（之後做，這次先畫方向草圖）：
- 互動式急症判斷：點選症狀，告訴你屬於四級中的哪一級，附出處。
- 計算工具：貓年齡換算、每日飲水量、IRIS 慢性腎病分期（輸入肌酸酐或 SDMA），結果附出處。
- 互動圖表：文獻庫的年份與主題分布；各縣市獸醫院與 24h 急診分布。
- 捲動敘事：重點文章隨捲動帶出圖表或插畫。
動態規範：
- 尊重系統的「減少動態效果」設定：開啟時直接顯示最終狀態。
- 急診相關畫面不能被動畫拖慢：急診按鈕與醫院清單要立刻可以按。
- 動畫短（0.2 到 1 秒）、只跑一次、不擋操作；不用自動輪播。
- 用 CSS 或少量原生 JavaScript 做得到，不依賴大型動畫框架。
- 螢幕報讀器直接讀到最終數字，不唸跑動中的數字。

六、要設計的頁面（依優先順序）
1. 首頁：插畫主視覺與標語、搜尋、半夜急診入口、數字跑碼列、四個主要功能（找獸醫院、查症狀看文章、學術文獻庫、品種圖鑑）、常見狀況入口、核心文章。
2. 文章頁：長篇醫療科普，內文用主調；註腳與參考文獻用期刊排版。固定區塊有草稿提醒（還沒人工審核的文章，要在內容前面標示）、導言、「何時該立刻就醫」紅旗症狀清單、「30 秒重點」三條、四級判斷（立刻急診、今天就醫、本週預約、居家觀察）、表格、找獸醫按鈕、相關文章、廣告位。
3. 獸醫院查詢：定位後依直線距離列出附近醫院；範圍 1、3、5、10、20 km 或不限；可疊加「24h 急診」「貓專科」篩選。每家醫院有名稱、標籤、地址、營業時間、距離，以及撥打電話、導航（交給 Google 地圖）、搜尋評價三個動作。要畫定位中、定位被拒、範圍內沒有醫院三種狀態。
4. 學術文獻庫：期刊排版。統計、搜尋、篩選（主題、來源類型、審核狀態）、中英切換、文獻卡片（書目格式、標籤、可展開的中文摘要、看原文、看引用這筆的文章）。
5. 文章列表：分類（健康、入門、行為、飲食、環境、階段）各配一個小插畫；子分類；每篇有標題、摘要、日期、閱讀時間、草稿標籤。
6. 加分：品種圖鑑、404 頁。

七、限制
- 技術：純 HTML／CSS 與少量原生 JavaScript，不用框架。內文用系統字體，不載整套中文字型；思源宋體與圓體只能用子集化字型。
- 無障礙：文字對比至少 4.5:1（WCAG AA）；手機點擊區至少 44×44px；急診、24h 等狀態不能只靠顏色區分；所有功能都能用鍵盤操作。
- 圖示：同一套線條 SVG 圖示，不用 emoji。
- 圖片：多數文章沒有封面圖，版面要在沒有圖的情況下也好看。插畫由設計師繪製，不要 AI 生成的照片風圖片。
- 資料：醫院資料來自政府公開登記，只有名稱、地址、電話、營業時間（文字，無法可靠判斷「營業中」）、是否 24h、是否貓專科、座標；沒有評分、沒有照片。文獻資料有題名、作者、期刊、年份、DOI 或 PMID、審核狀態、中文摘要，以及被哪些文章引用。
- 廣告：每頁最多兩到三個，要標「贊助」，不能夾在急診資訊中間。手機底部黏貼式廣告要不要保留還沒決定，請提出建議。
- 只做淺色版，不需要深色模式。
- 文字是繁體中文、台灣用語。

八、現況要避免的問題
- 太素：幾乎沒有插畫與動態，看起來像文件，不像網站。
- 手機導覽列放不下，右邊被切掉。
- emoji 當圖示，各家手機長得不一樣，也讓醫療內容顯得隨便。
- 同一頁用了五種不同的框（左邊粗線框、灰底框、黃底框、虛線框、白卡）。
- 首頁四張大卡一樣重，手機要滑三屏，而且看不到任何一篇文章。
- 沒有封面的文章，在列表放一個巨大的 emoji 當縮圖。
- 文獻庫的主題標籤中英混雜（taiwan、law 與「腎病 CKD」並列）。

九、交付物
- 手機（390px）與桌機（1440px）：首頁、文章頁、獸醫院查詢、學術文獻庫、文章列表。
- 獸醫院查詢的三種狀態：定位中、定位被拒、範圍內沒有醫院。
- 插畫：一組單線條貓插畫 SVG，至少包含首頁主視覺 1 張、分類入口 6 張、空狀態 3 張、404 頁 1 張。
- 動態規格：數字跑碼、脈搏線、插畫小動作、微互動的時長、速度曲線與觸發時機，以及「減少動態效果」開啟時的樣子（影片或 Figma 原型示意即可）。
- 第二階段互動工具的方向草圖：急症判斷、計算工具、互動圖表各一張。
- 元件表：色票（HEX 與用途）、兩套字級（主調與文獻區）、圖示組、按鈕、標籤、篩選、提示框、卡片、表格、註腳與參考文獻、文獻卡、廣告位。
- 一段設計說明：主調與文獻區怎麼銜接、動態怎麼不干擾急診。
- 檔案：Figma 優先，也接受 HTML／CSS 原型。

十、參考

- 主調骨架：GOV.UK、NHS 網站。期刊排版：報導者、紐約時報 Well 健康版、PubMed 的文獻頁。
```
