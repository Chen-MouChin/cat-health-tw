## 原型相對參考稿改了什麼

- 急診：頁首常駐紅色「24h 急診」；急診區塊的按鈕移進手機首屏（390×844 時下緣 628px，參考稿是 855px，在畫面外）。
- 數字跑碼：HTML 直接放最終數字，沒 JS、報讀器、搜尋引擎都讀得到；進入畫面才從 0 跑，五個一起約 1 秒到位（參考稿 22 在 0.3 秒、2,001 在 2 秒）。
- 小貓：臉改成兩眼＋粉紅倒三角鼻（2026-09-29 使用者指定。參考稿的眼鼻在 100px 左右糊成一團；三個圓點的版本看起來像三個泡泡），兩眼拉開、置中在兩耳下方；線條改主色 #3b6a50，鼻子用 `--blush` #dd7f8a；尾巴甩兩下就停（參考稿無限循環），載入後眨一次眼，點貓再甩尾巴、眨眼。
- 焦點框：黃底配近黑。參考稿的純黃外框在米色底上對比只有 1.25:1，看不到。
- Logo 換正式檔，金色脈搏線載入時畫一次；區塊標題前的脈搏記號進畫面時畫一次。
- 首頁主標用 jf 粉圓（Google Fonts 的 Huninn，以 `text=` 只載入主標的 9 個字）。
- 補上需求書有、參考稿沒有的：入口圖示、「我們怎麼寫」三點、完整頁尾與編輯方針連結。
- 連結都是真的站內路徑。原型專用的那段 script（點連結只顯示目的地）實作時要拿掉。

未定：手機底部錨定廣告要不要留；桌機版只是從手機版延伸，還沒細修。

## 實作（2026-09-29）

首頁已照原型改成 `frontend/index.html`，文字以使用者原稿 `ref-home-mockup.html` 為準（原型改過的副標、提示字、卡片說明、「推薦文章」都已恢復）。急診區塊依使用者要求不給就醫建議：拿掉原稿的「不要等天亮」與原型加的兩句，只留標題、四個狀況與找 24h 急診的按鈕。其他差異：廣告位在 AdSense 上線前隱藏；篇／筆／種／家由 build.py 依資料寫入，縣市數照原稿 22；粉圓改用站內子集字型；拿掉原型專用的連結攔截。
